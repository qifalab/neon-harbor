### 港湾生活入口与路线

欢迎页点击“港湾日常 · 巴士、电车与小轮”，或在游玩中打开“港湾日常”面板，查看实际班次、库存与配送任务。街坊日记读取实际活动、有效工时、工资、采购与事件；入口导航属于公开定位功能，不能把这些分项检查拼成无传送连续路线。

1. 从住宅经房门与实体楼梯到街道，步行到巴士站，停靠时按 E 上车并走到上层。
2. 返回下层车门，在站点正常下车；走进沿街小店与工坊。柜台购买需要店员到岗、营业、现货及足够现金。
3. 步行到码头，等待小轮靠泊，登船走上层并渡海；正常离船后进入对岸房间，再返航。
4. 乘双层电车观看街景；可去货栈领取已有配送订单并送到实际收货柜台。持货期间不能快速旅行。

车船内部使用 WASD，按住 Z 对准窄梯；下车须到下层车门，行驶中不能下车。最终资源的至少 20 分钟连续路线仍待验收。

### 建议游览路线

1. 点击“城市导览”，展开建筑查看楼内用途。前往“潮汐海事博物馆”，在门口按 E 进入，按 V 从人眼高度观察展品。
2. 沿大厅中轴走到电梯轿厢，按 E 选择观景层。到层后走出轿厢看海湾，再乘梯回到大厅，从入口返回街道。
3. 前往南岸渡轮码头，按 E 进入码头。渡轮停靠时按 E 登船，抵达北岸再按 E 下船。
4. 前往“山茶公寓”的生活楼层或“榕荫茶楼”的茶座与厨房。在“天际金融中心”的电梯列表检索 16F，先到 16 层，再沿实体楼梯上到 17F，走进“工程绘图室 1701”；也可继续乘梯至高处看海湾。
5. 导览底部选择西堤高架路或货运码头，从坡脚步行进入；也可找车开过两条高架，继续驶过跨海桥探索两岸。
6. 在导览筛选“南岸旧城”或“东湾天际线”，前往新地址，进入房间，沿实体楼梯上楼或乘电梯到观景层；回到大厅后从入口离开。

## v0.2 的变化（历史版本）

- 车辆与跟随镜头共用固定步快照插值，修复驾驶时的时间错位；镜头使用带高度的连续避障和缓慢恢复。
- 车辆按完整轮廓处理平移与旋转碰撞，持续阻挡交通车、墙角和窄杆；坡道支撑、头顶棚檐、上下车与非法存档位置均有安全检查。
- 车辆改为曲面车身、独立轮拱、玻璃内饰和清漆材质；人物采用自然比例与分段关节。新增天空云层、环境反射、店面、立面与街道材质细节。
- 默认精细画质。城市按 80 米街区异步请求详细实例数据，预取行驶方向、保留远景并回收离开的资源；碰撞与地面保持常驻，加载失败可在设置中重试。
- 车辆与人物按实际镜头距离切换细节等级，近景保留完整模型；帧时钟最多补算 15 个固定物理步，避免低帧率时额外慢动作，暂停和后台时间不会补进游戏。

这次改造建立了后续扩建和替换专业资产的基础。完整 AAA 美术、表演、剧情与内容规模仍需要继续制作。

## 首版可以玩什么

- 探索海滨城市的六个命名区域，在第三人称视角下行走、冲刺、跳跃和环顾镜头。
- 驾驶停放的跑车与轿车，体验交通车辆、转向、倒车、手刹、碰撞和损伤。
- 使用基础向前射击与弹匣装填，触发最高五星警戒；警车沿道路追踪，脱离视线后警戒逐级下降。
- 完成三项限时委托，获得首通奖励；再次挑战记录最佳用时，不重复发奖金。
- 查看小地图和城市地图，呼叫收费维修，在失败后于安全屋恢复，继续探索。
- 调整昼夜、画质、镜头灵敏度、音效和触屏控制；自动保存进度并导入/导出 JSON 存档。

| 委托 | 目标 | 限时 | 首通奖励 |
| --- | --- | --- | --- |
| 港湾速递 | 驾车依次到达 3 个送达点 | 150 秒 | $850 |
| 霓虹环线 | 驾车穿过 5 个检查点 | 100 秒 | $1,500 |
| 幽灵信号 | 到达信号站、解除追捕，再驾车返回安全屋 | 120 秒 | $2,000 |

建议先靠近出生点前方的青色跑车，按 E 上车，再打开委托中心接取「港湾速递」。一次只能进行一项委托，开始新委托前需要先完成或放弃当前委托。菜单打开时游戏暂停。

## 本地运行

需要 Node.js 22 或更高版本。项目以 MIT 许可证公开开源。游戏运行不需要安装 npm 依赖、后端服务或外部 CDN：

```sh
git clone https://github.com/qifalab/neon-harbor.git
cd neon-harbor
npm start
```

启动前会自动生成 `assets/city/chunks/` 和 `assets/metropolis/chunks/`，随后打开 `http://127.0.0.1:5173`。街区数据由源码生成，运行所需 GLB、纹理和渲染库随仓库分发，无需启动时向第三方下载素材。美术的可编辑来源与复现依赖另见下列素材记录。ES Modules 需要通过 HTTP 服务加载，请勿双击 HTML 文件。

允许局域网其他设备试玩：

```sh
npm start -- --host 0.0.0.0 --port 5173
```

## 构建与部署

```sh
npm run build
npm run preview
```

构建结果在 `dist/`。把整个目录交给 Nginx 或任意静态托管即可，无需长期运行 Node.js。页面和模块使用相对路径，可部署到域名根目录或项目子路径。

仓库已公开开源。单机试玩通过 GitHub Pages 发布，发布源为 **GitHub Actions**。`main` 的推送会进入 **GitHub Pages** 工作流，在规则测试、构建与浏览器验收通过后发布 `dist/`；也可以在 Actions 中手动选择分支运行以审查固定版本。Pages 只承载静态单机客户端，完整多人服务仍在开源仓库中运行。

发布后会再次访问实际 Pages 地址，核对发布提交、浏览器加载资源的 SHA-256、WebGL 初始化和菜单交互。截图与报告保存在该次发布的 `live-deployment-smoke` 产物中；`build-info.json` 记录版本、提交及构建文件摘要。

GitHub Pages 承载静态客户端。仓库提供独立的多人房间服务，支持 8 人共同探索、玩家与共用车辆同步及聊天。运行与部署见 [多人说明](docs/MULTIPLAYER_V07.md)。主站默认单人游玩；多人服务需要另外运行，当前没有随 Pages 发布的公网多人后端。

## 进度与游戏边界

自动存档记录现金、完成过的委托、最佳用时和安全位置；港湾样板另外保存车队运行时间与居民票据、街坊日程、库存、交易记录、在途配送及玩家随身物品。设置另行保存在当前浏览器。在室内或公共交通中保存，刷新后以步行状态回到相应安全入口；可驾驶车辆状态、生命值、弹药、旧委托和追捕会重新初始化。设置中可以导入/导出进度；导出的 JSON 不包含画质和音效设置。关闭浏览器期间不计算离线生产，清除站点数据会删除存档。

「车库与补给」目前提供 $150 的路边维修服务，恢复生命值与当前/附近车辆，追捕期间不可使用；尚无车辆收藏与改装。失败救援最多扣除 $200 并结束当前委托。旧委托保留首通奖励；港湾配送另外提供由店铺实际出资的每单 $12 运费。货栈与雇主资源有限，没有无限补货或自动发薪；买到的物品目前保留在随身库存，没有饮食消耗或属性恢复操作。

南岸保留原氛围行人，样板另有 20 名稳定逻辑街坊：三种不同岗位已有 CPU 验证，其余 17 人有真实部分生活逻辑；北岸 240 名居民保留原网络。港湾共同日历尚未覆盖全城与多人经济。近景人物共用全局 12 实例，人口逻辑不等于高细节驻留数量。三岸共享室内、程序化城区、完整动作与真实设备成本仍需制作和验收；接触阴影与环境代理不代表完成 3A 美术。

## 质量检查

本轮验证范围、实际结果、截图和设备限制见 [v0.8 验收记录](docs/QA_V08.md)。历史基线另见 [v0.6](docs/QA_V06.md)、[v0.3](docs/QA_V03.md) 和 [v0.2](docs/QA_V02.md) 验收记录；历史通过数量不代表当前源码通过。

历史预览实际通过429/429；当前候选实际通过432/432 CPU规则与0.8.0 / 215 build-info.assets清单条目构建。可比源码目录另实际415项，范围为历史409输入加六个新客户端模块，非全仓库 / 全测试计数。Office / South组件有限接受、三职业CPU通过、Motion两侧实际exit0、20原PNG慢走短步／停姿有限接受；完整动作、三型完整High、新整图图形CI、单会话完整生活路线与真实设备均待验收。Ferry50分钟 / CI130分钟是新预算，原40分钟失败保留。原199远程完整轮与三个paired High仍FAIL，详情和SHA收据见QA。

运行规则测试与构建不需要下载依赖：

```sh
npm test
npm run build
```

浏览器验收使用固定版本的 Playwright，实际启动 Chromium 与 WebGL：

```sh
npm ci
npx playwright install --with-deps chromium
npm run build
npm run test:e2e
```

如本机已有兼容 Chromium，可通过 `CHROMIUM_PATH=/absolute/path/to/chromium npm run test:e2e` 指定测试浏览器；CI 默认使用 Playwright 安装的版本。

北岸原有房间摄影工具分别运行 `npx playwright test --config=playwright.art.config.js` 和 `npx playwright test --config=playwright.detail.config.js`。前者的历史摄影范围为北岸 48 地址的 960 间流畅模式房间；后者对六间上层卧室、浴室、诊室、音乐教室及工坊采集精细模式近景。它们不代表新增 172 栋已经完成画面审查。本轮车辆、人物、家具、旧城室内、东湾室内及昼夜海滨证据统一记录于 [v0.8 验收记录](docs/QA_V08.md)，已归档截图保存在 `docs/qa/v08/`。

测试具体覆盖范围以 `tests/` 中的用例和 GitHub Actions 结果为准。游戏需要 WebGL 2，建议开启浏览器硬件加速；自动化浏览器验收使用 Chromium，不代表已验证所有浏览器和手机型号。「精细」是首次启动默认画质，启用动态阴影；玩家可自行选择「流畅」。系统不会因街区加载而自动降低近景画质。模拟碰撞与驾驶规则为轻量实现，不等同于完整车辆物理引擎。
