# 霓港 · Neon Harbor

[在线试玩单机版](https://neon-harbor.qifalab.cd.mba) · [发布与测试记录](https://github.com/qifalab/neon-harbor/actions/workflows/pages.yml)

一款可直接在浏览器运行的原创 3D 海滨城市游戏。步行探索街区、驾驶车辆、接取委托、躲避警车追捕，穿过跨海桥，乘地铁与渡轮，走进三岸的房间、楼梯、电梯与观景空间。

当前源码为 **v0.8 三岸室内与港湾生活样板**，验收及发布状态见 [v0.8 验收记录](docs/QA_V08.md)，公开站点版本以其 [`build-info.json`](https://neon-harbor.qifalab.cd.mba/build-info.json) 为准。本轮先从公开 v0.7 源码继续开发，随后查到并保留原 v0.8 检查点 `32ee844`，补回材质、建筑用途和导览加载覆盖；来源与楼层口径见验收记录。本项目独立设计城市、任务、美术与音效，与 Rockstar Games 或 GTA 系列没有关联，也未达到商业 3A 游戏的资产密度与表现。三岸基础见 [v0.8 计划](docs/REAL_CITY_V08_PLAN.md)，下一步世界模拟器与首个港湾样板见 [制作计划](docs/WORLD_SIMULATOR_PLAN.md) 和 [样板验收表](docs/HARBOR_SAMPLE_ACCEPTANCE.md)。

## v0.8 的变化

- **三岸室内目录**：北岸 48 栋、南岸旧城 96 栋、东湾 76 栋，共 220 栋、4,150 个连续楼层。旧城小楼采用两间房、中央通路、实体楼梯和后部电梯；东湾采用四房间共享布局。新增区域有按用途配置的家具及观景空间，尚未逐栋逐房手工精修。集装箱、设备、雕塑与地形不计为可进入建筑。
- **近景表面**：车漆、皮肤、衣料、皮革、金属和矿物表面分别处理微细节与粗糙度，衣物及部分软装增加小幅几何变化。效果需要近景画面审查，不能据此宣称塑料感已彻底解决。
- **环境反射与接触阴影**：反射环境加入实际建筑位置、尺寸生成的附近建筑代理；精细与均衡模式使用半分辨率深度遮蔽并合成接触阴影。这是近似环境反射，尚非实时街景反射、SSR 或平面反射。
- **按需驻留**：默认仍为精细画质。外部细节按距离加载与释放，室内只保留当前及相邻的三个楼层；大场景通过资源驻留预算控制开销。
- **交通与多人兼容**：保留分车道交通、圆滑转弯、跟车减速、路口放行、地铁及渡轮。独立房间服务继续支持最多 8 人，世界标识更新为 `neon-harbor-v08`；客户端与服务须使用相同版本。主站默认单人，尚未提供公网多人后端。
- **三种双层交通**：港湾样板新增潮汐街巴士、灯湾街电车及河口小轮，分别有下层车门、实体楼梯和可行走上层；班次在步行与室内探索期间继续运行。实际浏览器通行与画面结果单独登记，模型存在不等同于验收通过。
- **六家沿街小店**：双碗面家、芦岸印房、静潮茶室、晨罐烘焙、潮叶果铺和铜芦小馆有对应的外观与首层室内。加入曲面檐棚、店招、桌椅、货架及有来源记录的 CC0 扫描墙面与铺地；近处装配、远处回收。
- **有限的街坊经济**：南岸样板新增 20 名逻辑居民，三家店铺实际交易果蔬、茶饮与热汤面；居民到沿街柜台岗位、采购、通勤、配送和返家，钱与货按实际转移记录。玩家可购物或在货栈领货、送到柜台赚取运费，库存不会因重进街区而无限恢复。新店员岗位尚未全部接入室内工作路线。

**当前边界**：北岸 240 名居民继续使用既有链路；南岸新生活系统限于上述 20 人与三家交易店铺，没有覆盖全部新增建筑。4,150 层属于源码目录的结构范围，不代表每层画面和通行均已人工验收。工坊已接入两件 CC0 GLB 道具与本地 PBR 导入、按距驻留和释放；正式车船、蒙皮人物、逐场景精修、完整全城生活模拟和真实硬件帧率仍待制作或测量。首个样板的完整路线和上线仍在验证，功能、画面与性能分别记录。

### 港湾生活入口与路线

在欢迎页点击“港湾日常 · 巴士、电车与小轮”，或在游玩中打开“港湾日常”面板。面板读取实际班次、店铺库存与配送任务；可先定位到街坊住宅或站点，再用正常步行探索。

1. 从街坊住宅进入房间，沿实体楼梯返回街道；走到潮汐街巴士站等车，停靠时按 E 上车，沿车内楼梯到上层。
2. 返回下层车门，在站点按 E 下车；进入沿街小店看房间。果铺、茶室与面家的购物发生在沿街实体柜台，需要店员到岗、营业、现货及足够现金。
3. 前往河口码头，等小轮靠泊，登船走上层并渡到对岸；下船后探索北岸室内，再乘船返回南岸。
4. 沿灯湾街乘双层电车，走上层看街景；可顺路去芦岸货栈领货，再实际送到收货店铺。持有配送货物时不能快速旅行。

车船内部使用 WASD 行走，按住 Z 对准窄梯；下车须回到下层车门，行驶中不能下车。此路线是公开玩法说明，至少 20 分钟的完整连续路线是否通过见样板验收表。

## v0.7 的变化（历史版本）

统一建筑显示名称并保留稳定地址 ID 兼容旧存档；车流增加分车道路线、弧线转弯、提前跟车减速、路口信号与出口阻塞检查。首次提供 8 人私人探索房间、玩家与共用车辆同步及聊天。该版本的室内范围仍为北岸 48 栋、920 层；历史测试结果不作为 v0.8 验收结论。当前多人运行方法见 [多人说明](docs/MULTIPLAYER_V07.md)。

## v0.6 的变化（历史版本）

- **连续自然楼层**：48 栋北岸建筑从大厅到观景层共 920 层、3,680 个房间、872 段实体楼梯。首三层保留 0 / 4.2 / 8.4 米，其他楼层均匀分配剩余高度；天际金融中心有 63 层。电梯可检索全部楼层或房间名称。
- **逐栋室内细节**：48 套分别设计的上层用途，新增原创图形画作、房号、画框灯、踢脚与画轨、织物缝线和生活陈设。住宅、旅馆、医院、学校、工坊、档案与办公房间保留各自家具和尺度；相邻楼层有陈设变体，共享模型不称作逐房独立手工资产。
- **楼层驻留**：只驻留当前及相邻的三个精细楼层。楼梯换层保留重叠批次，释放远层的实例与标牌纹理；不会把整栋 63 层的陈设留在内存里。
- **真实居民往返**：240 名居民有持续的住处、岗位和午间到访目的地。沿经碰撞检查的步道及全幅斑马线走行，等行人信号，进入实际房间；岗位须有对应设施，白天留岗，夜间步行回家。
- **共用交通班次**：居民走过地铁双梯、渡轮坡道及轻轨/高铁的可见升降机，沿开放车门或船舷入口上车，上岸后继续走向目的地；四种线路使用与玩家相同的车辆和时钟。新增车站连桥、随门展开的登乘桥板及渡轮船舷开口。

**v0.6 当时范围**：全楼层通行与居民日常链路分别验收；逐房画面与动作表现继续按证据精修。房间使用现有室内骨架和按用途组织的原创模块，尚未逐层重做所有收分塔、双塔和异形外壳的建筑工程图。居民在楼内走实体楼梯，车站升降机服务他们的真实路径；玩家的轻轨、高铁与渡轮入口保留原 E 操作。当时南岸旧城与背景天际线尚未开放室内。

## v0.5 的变化（历史版本）

这轮直接回应海港不够壮观、内部空旷、不能自然上楼和地铁入口跳转的问题。

- **从海港开始**：主菜单取景于实际海滨，主按钮“漫步海港”进入可走步道，保留旧存档及旧城驾驶入口。三个海滨观察点能从导览抵达。
- **对岸天际线**：40 栋独立主塔与 36 栋中低层背景楼，包含收分、弧面、斜切、退台等轮廓，以及连续岸线和山脊。背景楼没有计算为可进入地址。
- **连续室内楼层**：48 栋北岸建筑各开放大厅、4.2 米二层、8.4 米三层及公共观景层，共 192 个公共层、768 个功能房间。每栋两段实体楼梯连接低层，原电梯继续升降至观景层。三层分别补充对应地址的新用途。
- **房间尺度**：低层功能房间限制在 19 × 18 米以内，配置完整墙体、门洞、顶棚及家具，住宅和医疗空间保留各自更小的尺度；楼梯穿过真实楼板开洞。
- **步行下到地铁**：三座地铁站各有两段 40 级楼梯、中途平台、站厅、售票机、闸机通道和站台；街口无需按 E，按方向行走即可下楼和返回。上车及下车仍在车辆停靠时按 E。
- **光照与表面**：按海港视距重做雾和天空，区分玻璃与金属响应，海面使用世界尺度动态波纹。远景幕墙保留可辨认的结构节奏，细部按观察位置加载和释放，默认仍为 High。

参考项目源码分析、固定提交和具体取舍见 [渲染与美术参考](docs/REFERENCE_ART_DIRECTION_V05.md)。港湾设计与资源策略见 [港湾制作记录](docs/HARBOR_V05.md)。实际规则、浏览器路线、实拍及发布状态分别记入验收文档；没有以规则测试数量代替画面质量判断。

**v0.5 当时范围**：开放室内限于上述北岸地址，每栋四个公共层，尚非每个自然楼层。南岸旧城及新对岸背景楼尚未开放室内。轻轨、高铁、渡轮仍保留原交互入口，只有地铁在本轮打通连续楼梯。角色动作、全址美术审查、真实跨街通勤和硬件性能测量仍需继续制作，当前不称为完成的商业 3A 城市。

## v0.4 的变化（历史版本）

- 48 栋独立外观设计，192 个中文店招，逐栋加入钟楼、门廊、帆索、雕塑、遮阳、橱窗与屋面设备；旧城有空调、晾衣和修补墙面。
- 144 个公共楼层分别设计用途与家具，形成 576 个功能区。住宅有起居、睡眠和厨房，餐饮有卡座和备餐，医院、音乐学院、实验室和档案馆配置对应物件。功能区不等同于自然楼层或独立住宅。
- 新增三张原创材质，石材、粉墙、木纹、织物、皮革与金属采用不同尺度、凹凸和粗糙度。细节资源仍按街区加载与释放。
- 两条共 1.2 公里的可驾驶高架、可步行进入的货运码头、28 个货柜和两座岸桥。桥面与地面分别支撑车辆，坡道连续，桥上保存后回到安全入口。
- 240 名居民拥有姓名、职业和四时段活动，聊天后继续出行，带有阅读、摄影、喝茶和采购动作。三处巴士雨棚有候车居民；巴士为静态街景，尚不可乘。
- 按 **V** 或右上角按钮切换步行视角，可近看房间与街道；室内跟随镜头缩短。导览能展开每栋三个公共层及房间用途，并前往高架与港口入口。

逐项实现见 [建筑](docs/ARCHITECTURE_V04.md)、[室内](docs/INTERIORS_V04.md)、[居民](docs/CITIZENS_V04.md) 与 [基础设施](docs/INFRASTRUCTURE_V04.md)。居民保持在经过碰撞检查的局部步道活动，尚不跨机动车道或自动搭乘公共交通。

- 4 条公共交通线路、10 座站点、17 辆运营车船，包含地铁、轻轨、高铁和渡轮。进入站台、候车、上车、实际行驶、到站下车；地下空间保留独立高度。
- 240 名逻辑居民，8 套外观，附近最多 32 个完整人物和 112 个远景剪影，支持行走、停留、交谈、地点提示与避车。北岸另有可驾驶车辆和道路交通。

- 城市导览支持检索48个地址及交通站点，可选快速旅行；任务与追捕中不能快速旅行。楼内或交通运行中保存，重新载入会安全回到对应建筑或站点的地面入口。

该历史版本采用原创程序化建筑与人物，尚未达到商业 AAA 游戏的手工资产密度。历史制作范围见 [跨海城市计划](docs/METROPOLIS_PLAN.md)，北岸逐栋记录见 [48栋建筑档案](docs/CITY_CATALOG.md)。

### 建议游览路线

1. 点击“城市导览”，展开建筑查看楼内用途。前往“潮汐海事博物馆”，在门口按 E 进入，按 V 从人眼高度观察展品。
2. 沿大厅中轴走到电梯轿厢，按 E 选择观景层。到层后走出轿厢看海湾，再乘梯回到大厅，从入口返回街道。
3. 前往南岸渡轮码头，按 E 进入码头。渡轮停靠时按 E 登船，抵达北岸再按 E 下船。
4. 前往“山茶公寓”的生活楼层或“榕荫茶楼”的茶座与厨房。在“天际金融中心”的电梯列表检索 16F，先到 16 层，再沿实体楼梯上到 17F，走进“工程绘图室 1701”；也可继续乘梯至高处看海湾。
5. 导览底部选择西堤高架路或货运码头，从坡脚步行进入；也可找车开过两条高架，继续驶过跨海桥探索两岸。
6. 在导览筛选“南岸旧城”或“东湾天际线”，前往新地址，进入房间，沿实体楼梯上楼或乘电梯到观景层；回到大厅后从入口离开。

## v0.2 的变化（历史版本）

- 车辆与跟随镜头共用固定步快照插值，修复驾驶时的时间错位；镜头使用带高度的连续避障和缓慢恢复。
- 车辆按完整轮廓处理平移与旋转碰撞，持续阻挡交通车、墙角和窄杆；坡道支撑、头顶棚檐、上下车与非法存档位置均有安全检查。
- 车辆改为曲面车身、独立轮拱、玻璃内饰和清漆材质；人物采用自然比例与分段关节。新增天空云层、环境反射、店面、立面与街道材质细节。
- 默认精细画质。城市按 80 米街区异步请求详细实例数据，预取行驶方向、保留远景并回收离开的资源；碰撞与地面保持常驻，加载失败可在设置中重试。
- 车辆与人物按实际镜头距离切换细节等级，近景保留完整模型；帧时钟最多补算 15 个固定物理步，避免低帧率时额外慢动作，暂停和后台时间不会补进游戏。

这次改造建立了后续扩建和替换专业资产的基础。完整 AAA 美术、表演、剧情与内容规模仍需要继续制作。

## 首版可以玩什么

- 探索海滨城市的六个命名区域，在第三人称视角下行走、冲刺、跳跃和环顾镜头。
- 驾驶停放的跑车与轿车，体验交通车辆、转向、倒车、手刹、碰撞和损伤。
- 使用基础向前射击与弹匣装填，触发最高五星警戒；警车沿道路追踪，脱离视线后警戒逐级下降。
- 完成三项限时委托，获得首通奖励；再次挑战记录最佳用时，不重复发奖金。
- 查看小地图和城市地图，呼叫收费维修，在失败后于安全屋恢复，继续探索。
- 调整昼夜、画质、镜头灵敏度、音效和触屏控制；自动保存进度并导入/导出 JSON 存档。

## 本地运行

需要 Node.js 22 或更高版本。项目以 MIT 许可证公开开源。游戏运行不需要安装 npm 依赖、后端服务或外部 CDN：

```sh
git clone https://github.com/qifalab/neon-harbor.git
cd neon-harbor
npm start
```

启动前会自动生成 `assets/city/chunks/` 和 `assets/metropolis/chunks/`，随后打开 `http://127.0.0.1:5173`。街区资源由源码生成，无需单独下载素材。ES Modules 需要通过 HTTP 服务加载，请勿双击 HTML 文件。

允许局域网其他设备试玩：

```sh
npm start -- --host 0.0.0.0 --port 5173
```

## 构建与部署

```sh
npm run build
npm run preview
```

构建结果在 `dist/`。把整个目录交给 Nginx 或任意静态托管即可，无需长期运行 Node.js。页面和模块使用相对路径，可部署到域名根目录或项目子路径。

仓库已公开开源。单机试玩通过 GitHub Pages 发布，发布源为 **GitHub Actions**。在 Actions 中手动运行 **GitHub Pages** 工作流，即可在规则测试、构建与浏览器验收通过后发布 `dist/`。每次手动发布对应选中的分支版本；普通提交只运行 CI。

发布后会再次访问实际 Pages 地址，核对发布提交、浏览器加载资源的 SHA-256、WebGL 初始化和菜单交互。截图与报告保存在该次发布的 `live-deployment-smoke` 产物中；`build-info.json` 记录版本、提交及构建文件摘要。

GitHub Pages 承载静态客户端。仓库提供独立的多人房间服务，支持 8 人共同探索、玩家与共用车辆同步及聊天。运行与部署见 [多人说明](docs/MULTIPLAYER_V07.md)。主站默认单人游玩；多人服务需要另外运行，当前没有随 Pages 发布的公网多人后端。

## 进度与游戏边界

自动存档记录现金、完成过的委托、最佳用时和安全位置；港湾样板另外保存车队运行时间与居民票据、街坊日程、库存、交易记录、在途配送及玩家随身物品。设置另行保存在当前浏览器。在室内或公共交通中保存，刷新后以步行状态回到相应安全入口；可驾驶车辆状态、生命值、弹药、旧委托和追捕会重新初始化。设置中可以导入/导出进度；导出的 JSON 不包含画质和音效设置。关闭浏览器期间不计算离线生产，清除站点数据会删除存档。

「车库与补给」目前提供 $150 的路边维修服务，恢复生命值与当前/附近车辆，追捕期间不可使用；尚无车辆收藏与改装。失败救援最多扣除 $200 并结束当前委托。旧委托保留首通奖励；港湾配送另外提供由店铺实际出资的每单 $12 运费。货栈与雇主资源有限，没有无限补货或自动发薪；买到的物品目前保留在随身库存，没有饮食消耗或属性恢复操作。

南岸保留原有氛围行人，样板另有 20 名持续模拟的街坊，近处最多驻留 12 个完整人物；北岸 240 名居民保留原有生活网络。三岸 220 栋、4,150 层以共享布局为主，尚无覆盖全城的同等生活模拟。多人当前是私人房间共同探索，尚无账号、共享任务或完整服务器物理反作弊；新店铺库存、居民经济与车队票据仍由客户端本地模拟，尚未由多人服务统一核算。画面使用原创程序化模型、授权扫描材质和两件正式 CC0 工坊道具，仍缺专业角色、完整骨骼动作库、正式车船与手工制作的高密度城区，接触阴影与环境代理也不等同于完成 3A 美术。

## 质量检查

本轮验证范围、实际结果、截图和设备限制见 [v0.8 验收记录](docs/QA_V08.md)。历史基线另见 [v0.6](docs/QA_V06.md)、[v0.3](docs/QA_V03.md) 和 [v0.2](docs/QA_V02.md) 验收记录；历史通过数量不代表当前源码通过。

当前正式道具版本在隔离目录完整规则 **311/311 通过，0 失败、0 取消、0 跳过**；选择性合并后，主工作区全部 156 项运行资源、43 份 npm 测试与 package / lock 字节一致，构建通过，复用该次规则结果。[原始结果与主工作区核对](docs/qa/art-pilot/root-integration-2026-10-04/README.md)保留，未称为主工作区重新运行。此前居民通行修订的 [302/302 原始结果](docs/qa/transit-crossing-repair/final-checks/README.md)属于两件 GLB 合入前的版本。`0330df7` 候选的 11 个游戏分片、27 个真实浏览器场景全部通过；同轮多人因重复启动执行追踪在进入页面前失败，整轮仍失败。关闭测试框架自动执行追踪、保留两个实际浏览器各自的追踪后，本地多人 **2/2 通过，无重试**。[三地址实走 / 五张原生 High 图](docs/qa/art-final/native-review/README.md)已抽样审查，住宅起步连续路线正在核验，最终 Pages 门禁尚未通过，公开站点仍为 v0.7。历史规则、浏览器失败与后续复核各自保留在 QA，不追记成首轮全绿。

已查看并归档 [8 张车辆/人物图、3 张家具图及 AO 诊断、4 张昼夜海滨图](docs/QA_V08.md#已归档画面与待补范围)。局部软装和接触阴影有改善，但同机位家具场景三角形增加约 62.4%；海滨对照主要证明渲染稳定，未显示整体画质大幅提升。参数、画面限制及成本均见 QA，这些样本不能作为逐栋人工验收、硬件性能或 3A 品质证据。

运行规则测试与构建不需要下载依赖：

```sh
npm test
npm run build
```

浏览器验收使用固定版本的 Playwright，实际启动 Chromium 与 WebGL：

```sh
npm ci
npx playwright install --with-deps chromium
npm run build
npm run test:e2e
```

如本机已有兼容 Chromium，可通过 `CHROMIUM_PATH=/absolute/path/to/chromium npm run test:e2e` 指定测试浏览器；CI 默认使用 Playwright 安装的版本。

北岸原有房间摄影工具分别运行 `npx playwright test --config=playwright.art.config.js` 和 `npx playwright test --config=playwright.detail.config.js`。前者的历史摄影范围为北岸 48 地址的 960 间流畅模式房间；后者对六间上层卧室、浴室、诊室、音乐教室及工坊采集精细模式近景。它们不代表新增 172 栋已经完成画面审查。本轮车辆、人物、家具、旧城室内、东湾室内及昼夜海滨证据统一记录于 [v0.8 验收记录](docs/QA_V08.md)，已归档截图保存在 `docs/qa/v08/`。

测试具体覆盖范围以 `tests/` 中的用例和 GitHub Actions 结果为准。游戏需要 WebGL 2，建议开启浏览器硬件加速；自动化浏览器验收使用 Chromium，不代表已验证所有浏览器和手机型号。「精细」是首次启动默认画质，启用动态阴影；玩家可自行选择「流畅」。系统不会因街区加载而自动降低近景画质。模拟碰撞与驾驶规则为轻量实现，不等同于完整车辆物理引擎。
