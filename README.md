# 霓港 · Neon Harbor

[在线试玩单机版](https://neon-harbor.qifalab.cd.mba) · [发布与测试记录](https://github.com/qifalab/neon-harbor/actions/workflows/pages.yml)

一款可直接在浏览器运行的原创 3D 海滨城市游戏。步行探索街区、驾驶车辆、接取委托、躲避警车追捕，穿过跨海桥，乘地铁与渡轮，走进北岸的公共建筑与观景层。

当前源码为 **v0.6 Occupied City 楼内生活版**。公开站点版本以其 `build-info.json` 为准。本项目借鉴开放世界城市游戏的玩法形式，独立设计城市、任务、美术与音效，与 Rockstar Games 或 GTA 系列没有关联，也不代表已经实现 GTA 5/6 的完整内容与规模。首版范围见 [首版实施计划](docs/PLAN.md)，完整后续制作计划见 [真实城市制作计划](docs/REAL_CITY_V05_PLAN.md)，本轮计划与验收见 [v0.6 计划](docs/REAL_CITY_V06_PLAN.md) 和 [v0.6 验收记录](docs/QA_V06.md)，成品方向与资产制作顺序见 [美术与世界制作计划](docs/WORLD_PRODUCTION.md)。

## v0.6 的变化

- **连续自然楼层**：48 栋北岸建筑从大厅到观景层共 920 层、3,680 个房间、872 段实体楼梯。首三层保留 0 / 4.2 / 8.4 米，其他楼层均匀分配剩余高度；天际金融中心有 63 层。电梯可检索全部楼层或房间名称。
- **逐栋室内细节**：48 套分别设计的上层用途，新增原创图形画作、房号、画框灯、踢脚与画轨、织物缝线和生活陈设。住宅、旅馆、医院、学校、工坊、档案与办公房间保留各自家具和尺度；相邻楼层有陈设变体，共享模型不称作逐房独立手工资产。
- **楼层驻留**：只驻留当前及相邻的三个精细楼层。楼梯换层保留重叠批次，释放远层的实例与标牌纹理；不会把整栋 63 层的陈设留在内存里。
- **真实居民往返**：240 名居民有持续的住处、岗位和午间到访目的地。沿经碰撞检查的步道及全幅斑马线走行，等行人信号，进入实际房间；岗位须有对应设施，白天留岗，夜间步行回家。
- **共用交通班次**：居民走过地铁双梯、渡轮坡道及轻轨/高铁的可见升降机，沿开放车门或船舷入口上车，上岸后继续走向目的地；四种线路使用与玩家相同的车辆和时钟。新增车站连桥、随门展开的登乘桥板及渡轮船舷开口。

**本轮边界**：全楼层通行与居民日常链路分别验收；逐房画面与动作表现继续按证据精修。房间使用现有室内骨架和按用途组织的原创模块，尚未逐层重做所有收分塔、双塔和异形外壳的建筑工程图。居民在楼内走实体楼梯，车站升降机服务他们的真实路径；玩家的轻轨、高铁与渡轮入口保留原 E 操作。南岸旧城与背景天际线尚未开放室内。

## v0.5 的变化（历史版本）

这轮直接回应海港不够壮观、内部空旷、不能自然上楼和地铁入口跳转的问题。

- **从海港开始**：主菜单取景于实际海滨，主按钮“漫步海港”进入可走步道，保留旧存档及旧城驾驶入口。三个海滨观察点能从导览抵达。
- **对岸天际线**：40 栋独立主塔与 36 栋中低层背景楼，包含收分、弧面、斜切、退台等轮廓，以及连续岸线和山脊。背景楼没有计算为可进入地址。
- **连续室内楼层**：48 栋北岸建筑各开放大厅、4.2 米二层、8.4 米三层及公共观景层，共 192 个公共层、768 个功能房间。每栋两段实体楼梯连接低层，原电梯继续升降至观景层。三层分别补充对应地址的新用途。
- **房间尺度**：低层功能房间限制在 19 × 18 米以内，配置完整墙体、门洞、顶棚及家具，住宅和医疗空间保留各自更小的尺度；楼梯穿过真实楼板开洞。
- **步行下到地铁**：三座地铁站各有两段 40 级楼梯、中途平台、站厅、售票机、闸机通道和站台；街口无需按 E，按方向行走即可下楼和返回。上车及下车仍在车辆停靠时按 E。
- **光照与表面**：按海港视距重做雾和天空，区分玻璃与金属响应，海面使用世界尺度动态波纹。远景幕墙保留可辨认的结构节奏，细部按观察位置加载和释放，默认仍为 High。

参考项目源码分析、固定提交和具体取舍见 [渲染与美术参考](docs/REFERENCE_ART_DIRECTION_V05.md)。港湾设计与资源策略见 [港湾制作记录](docs/HARBOR_V05.md)。实际规则、浏览器路线、实拍及发布状态分别记入验收文档；没有以规则测试数量代替画面质量判断。

**v0.5 当时范围**：开放室内限于上述北岸地址，每栋四个公共层，尚非每个自然楼层。南岸旧城及新对岸背景楼尚未开放室内。轻轨、高铁、渡轮仍保留原交互入口，只有地铁在本轮打通连续楼梯。角色动作、全址美术审查、真实跨街通勤和硬件性能测量仍需继续制作，当前不称为完成的商业 3A 城市。

## v0.4 的变化（前一版本）

- 48 栋独立外观设计，192 个中文店招，逐栋加入钟楼、门廊、帆索、雕塑、遮阳、橱窗与屋面设备；旧城有空调、晾衣和修补墙面。
- 144 个公共楼层分别设计用途与家具，形成 576 个功能区。住宅有起居、睡眠和厨房，餐饮有卡座和备餐，医院、音乐学院、实验室和档案馆配置对应物件。功能区不等同于自然楼层或独立住宅。
- 新增三张原创材质，石材、粉墙、木纹、织物、皮革与金属采用不同尺度、凹凸和粗糙度。细节资源仍按街区加载与释放。
- 两条共 1.2 公里的可驾驶高架、可步行进入的货运码头、28 个货柜和两座岸桥。桥面与地面分别支撑车辆，坡道连续，桥上保存后回到安全入口。
- 240 名居民拥有姓名、职业和四时段活动，聊天后继续出行，带有阅读、摄影、喝茶和采购动作。三处巴士雨棚有候车居民；巴士为静态街景，尚不可乘。
- 按 **V** 或右上角按钮切换步行视角，可近看房间与街道；室内跟随镜头缩短。导览能展开每栋三个公共层及房间用途，并前往高架与港口入口。

逐项实现见 [建筑](docs/ARCHITECTURE_V04.md)、[室内](docs/INTERIORS_V04.md)、[居民](docs/CITIZENS_V04.md) 与 [基础设施](docs/INFRASTRUCTURE_V04.md)。居民保持在经过碰撞检查的局部步道活动，尚不跨机动车道或自动搭乘公共交通。

## v0.3 的变化

- 保留南岸驾驶城区，新增约 1.48 × 0.99 公里的北岸、跨海桥与六个街区。48 栋建筑有独立地址、用途、尺寸、轮廓和门牌。
- v0.3–v0.4 每栋开放公共大厅、一个主题楼层与观景层；v0.5 已扩展为三个连续低层与观景层。家具与墙体有碰撞，电梯实体轿厢连续升降，可以往返街道。
- 4 条公共交通线路、10 座站点、17 辆运营车船，包含地铁、轻轨、高铁和渡轮。进入站台、候车、上车、实际行驶、到站下车；地下空间保留独立高度。
- 240 名逻辑居民，8 套外观，附近最多 32 个完整人物和 112 个远景剪影，支持行走、停留、交谈、地点提示与避车。北岸另有可驾驶车辆和道路交通。
- 原创石材、旧墙、木地板和釉砖贴图实际用于游戏；12 个北岸资源分块按需请求与回收，近处细节保留。见 [素材来源](docs/ASSET_PROVENANCE.md)。
- 城市导览支持检索48个地址及交通站点，可选快速旅行；任务与追捕中不能快速旅行。楼内或交通运行中保存，重新载入会安全回到对应建筑或站点的地面入口。

新内容仍采用原创程序化建筑与人物；当前 v0.6 已把北岸 48 地址连为连续楼层。它是一版可玩的城市系统扩展，尚未达到商业 AAA 游戏的手工资产密度。制作范围及验收项见 [跨海城市计划](docs/METROPOLIS_PLAN.md)，逐栋记录见 [48栋建筑档案](docs/CITY_CATALOG.md)。

### 建议游览路线

1. 点击“城市导览”，展开建筑查看楼内用途。前往“潮汐海事博物馆”，在门口按 E 进入，按 V 从人眼高度观察展品。
2. 沿大厅中轴走到电梯轿厢，按 E 选择观景层。到层后走出轿厢看海湾，再乘梯回到大厅，从入口返回街道。
3. 前往“旧城 · 天星码头”，按 E 进入码头。渡轮停靠时按 E 登船，抵达北岸再按 E 下船。
4. 前往“山茶公寓”的生活楼层或“榕荫茶楼”的茶座与厨房。在“天际金融中心”的电梯列表检索 16F，先到 16 层，再沿实体楼梯上到 17F，走进“工程绘图室 1701”；也可继续乘梯至高处看海湾。
5. 导览底部选择西环高架或货运码头，从坡脚步行进入；也可找车开过两条高架，继续驶过跨海桥探索两岸。

## v0.2 的变化

- 车辆与跟随镜头共用固定步快照插值，修复驾驶时的时间错位；镜头使用带高度的连续避障和缓慢恢复。
- 车辆按完整轮廓处理平移与旋转碰撞，持续阻挡交通车、墙角和窄杆；坡道支撑、头顶棚檐、上下车与非法存档位置均有安全检查。
- 车辆改为曲面车身、独立轮拱、玻璃内饰和清漆材质；人物采用自然比例与分段关节。新增天空云层、环境反射、店面、立面与街道材质细节。
- 默认精细画质。城市按 80 米街区异步请求详细实例数据，预取行驶方向、保留远景并回收离开的资源；碰撞与地面保持常驻，加载失败可在设置中重试。
- 车辆与人物按实际镜头距离切换细节等级，近景保留完整模型；帧时钟最多补算 15 个固定物理步，避免低帧率时额外慢动作，暂停和后台时间不会补进游戏。

这次改造建立了后续扩建和替换专业资产的基础。完整 AAA 美术、表演、剧情与内容规模仍需要继续制作。

## 首版可以玩什么

- 探索海滨城市的六个命名区域，在第三人称视角下行走、冲刺、跳跃和环顾镜头。
- 驾驶停放的跑车与轿车，体验交通车辆、转向、倒车、手刹、碰撞和损伤。
- 使用基础向前射击与弹匣装填，触发最高五星警戒；警车沿道路追踪，脱离视线后警戒逐级下降。
- 完成三项限时委托，获得首通奖励；再次挑战记录最佳用时，不重复发奖金。
- 查看小地图和城市地图，呼叫收费维修，在失败后于安全屋恢复，继续探索。
- 调整昼夜、画质、镜头灵敏度、音效和触屏控制；自动保存进度并导入/导出 JSON 存档。

| 委托 | 目标 | 限时 | 首通奖励 |
| --- | --- | --- | --- |
| 港湾速递 | 驾车依次到达 3 个送达点 | 150 秒 | $850 |
| 霓虹环线 | 驾车穿过 5 个检查点 | 100 秒 | $1,500 |
| 幽灵信号 | 到达信号站、解除追捕，再驾车返回安全屋 | 120 秒 | $2,000 |

建议先靠近出生点前方的青色跑车，按 E 上车，再打开委托中心接取「港湾速递」。一次只能进行一项委托，开始新委托前需要先完成或放弃当前委托。菜单打开时游戏暂停。

## 本地运行

需要 Node.js 22 或更高版本。项目以 MIT 许可证公开开源。游戏运行不需要安装 npm 依赖、后端服务或外部 CDN：

```sh
git clone https://github.com/qifalab/neon-harbor.git
cd neon-harbor
npm start
```

启动前会自动生成 `assets/city/chunks/` 和 `assets/metropolis/chunks/`，随后打开 `http://127.0.0.1:5173`。街区资源由源码生成，无需单独下载素材。ES Modules 需要通过 HTTP 服务加载，请勿双击 HTML 文件。

允许局域网其他设备试玩：

```sh
npm start -- --host 0.0.0.0 --port 5173
```

## 构建与部署

```sh
npm run build
npm run preview
```

构建结果在 `dist/`。把整个目录交给 Nginx 或任意静态托管即可，无需长期运行 Node.js。页面和模块使用相对路径，可部署到域名根目录或项目子路径。

仓库已公开开源。单机试玩通过 GitHub Pages 发布，发布源为 **GitHub Actions**。在 Actions 中手动运行 **GitHub Pages** 工作流，即可在规则测试、构建与浏览器验收通过后发布 `dist/`。每次手动发布对应选中的分支版本；普通提交只运行 CI。

发布后会再次访问实际 Pages 地址，核对发布提交、浏览器加载资源的 SHA-256、WebGL 初始化和菜单交互。截图与报告保存在该次发布的 `live-deployment-smoke` 产物中；`build-info.json` 记录版本、提交及构建文件摘要。

GitHub Pages 承载静态客户端。未来多人版仍可复用此客户端托管方式，房间服务器、实时同步与数据库需部署在独立后端。

## 进度与游戏边界

自动存档记录现金、完成过的委托、最佳用时和位置，设置另行保存在当前浏览器。刷新后从已保存位置以步行状态继续，车辆状态、生命值、弹药、进行中的委托和追捕会重新初始化。设置中可以导入/导出进度；导出的 JSON 不包含画质和音效设置。清除站点数据会删除浏览器存档。

「车库与补给」目前提供 $150 的路边维修服务，恢复生命值与当前/附近车辆，追捕期间不可使用；尚无车辆收藏与改装。失败救援最多扣除 $200 并结束当前委托。经济系统围绕三项首通奖励，尚未提供持续赚钱的商业模拟。

南岸行人仍是氛围角色，北岸 240 名居民有实际工作、住处、到访及交通链路，并提供身份和当前目的地对话。可进入建筑目前限于北岸目录中的48栋，共开放920个连续楼层；南岸背景建筑尚未开放室内。尚无多人联机、丰富武器种类或长篇剧情。画面由原创程序化几何和材质生成；曲面车辆、人物结构与街景细节已重做，但还没有专业角色扫描、完整骨骼动作库或手工制作的高密度城区。

## 质量检查

本轮验证范围、实测数据和设备限制见 [v0.3 验收记录](docs/QA_V03.md)；原有驾驶与镜头测试基线见 [v0.2 验收记录](docs/QA_V02.md)。

运行规则测试与构建不需要下载依赖：

```sh
npm test
npm run build
```

浏览器验收使用固定版本的 Playwright，实际启动 Chromium 与 WebGL：

```sh
npm ci
npx playwright install --with-deps chromium
npm run build
npm run test:e2e
```

如本机已有兼容 Chromium，可通过 `CHROMIUM_PATH=/absolute/path/to/chromium npm run test:e2e` 指定测试浏览器；CI 默认使用 Playwright 安装的版本。

房间画面审查分别运行 `npx playwright test --config=playwright.art.config.js` 和 `npx playwright test --config=playwright.detail.config.js`。前者从正常导览、电梯及步行操作采集全 48 地址的 960 张流畅模式房间截图；后者对六间上层卧室、浴室、诊室、音乐教室及工坊采集精细模式 960×600 近景，并确认实际画布分辨率。截图数量、画质及审查范围单独记入 v0.6 验收记录。

测试具体覆盖范围以 `tests/` 中的用例和 GitHub Actions 结果为准。游戏需要 WebGL 2，建议开启浏览器硬件加速；自动化浏览器验收使用 Chromium，不代表已验证所有浏览器和手机型号。「精细」是首次启动默认画质，启用动态阴影；玩家可自行选择「流畅」。系统不会因街区加载而自动降低近景画质。模拟碰撞与驾驶规则为轻量实现，不等同于完整车辆物理引擎。

## 开发结构

| 路径 | 内容 |
| --- | --- |
| `index.html`、`styles.css` | 页面、菜单、HUD 与触屏控件 |

| `src/metropolis-people.js`、`src/city-exploration.js`、`src/city-guide.js` | 居民、内外空间切换、存档安全与城市导览 |
| `src/models.js`、`src/atmosphere.js` | 车辆与人物、天空、环境反射和光色 |
| `src/collision.js`、`src/ground-support.js` | 连续轮廓碰撞、空间索引、车辆地表支撑 |
| `src/frame-clock.js`、`src/presentation.js`、`src/camera.js` | 有界固定步时钟、插值呈现、状态跳变、跟随镜头和避障 |

| `tests/` | 游戏规则与浏览器验收 |
| `docs/` | 历史范围、本轮验收、美术与世界制作计划 |
