# Visible western harbour ridge v2

This original, editable geometry recipe replaces the ten separate radial West mounds with one connected asymmetric longitudinal height field, broad saddles, uneven shoulders and five branching drainage cuts. It stays inside the original West union [-1076,-18.5,-1439] to [-790,160.5,-495], with a closed submerged skirt and bottom.

The actual two closed North8b6 Day cameras see West, not the earlier Northern ridge. Their independent clipped-triangle projection proof changes hundreds of screen columns. This fixes the source target error explicitly; the original North8b6 Day art failure and unexecuted Night method are preserved. CPU projection cannot prove rendered occlusion, lighting, shader compatibility or artistic quality. New actual High originals remain required.

Runtime source is src/metropolis-western-ridge.js. src/metropolis-northern-ridge.js only changes extraction to the semantic westernRange; its generated Northern position, normal, color, UV, index, material and two original map bytes stay exact. Source metropolis-world.js and all roads, streaming, physics, entries, residents, shops and trees stay unchanged.

Actual West geometry is8032 triangles/4018 vertices/224984 buffer bytes in one draw; totalWest+North24784 triangles/two draws. The intermediate producer including the retained original12 Northern source cones and scratch is283472 bytes, under the original300000 limit. Existing aggregateWest triangle cap30000 is unchanged. The legacy3000 quota for each of ten independent mounds does not describe this single connected owner. No texture or global lighting/exposure change is introduced.

The existing mineral surface shader is retained with pervertex slope/soil/rock colors and broad geological bands; no imported images or custom shader pipeline is added. Generated decorative mountains supply no collision or walkable terrain. Original geometry/recipe is CC0-1.0; JavaScript is MIT.
