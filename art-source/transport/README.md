# Authored transport source archive candidate

This supplement preserves the actual C authored transport sources and licence originals for Serein D11 bus, Vesper T9 tram and Lacuna F26 ferry. It is prepared only under `/tmp`; it has not changed ROOT, the isolated integration runtime, or any sealed candidate. The active original D tour is not footage or acceptance evidence for these new assets.

`candidate-files.json` maps every selected, byte-verified payload file to `art-source/transport/{bus,tram,ferry}` or `docs/qa/authored-transport`. Original files are copied without rewriting; their former `/tmp` paths and optional-not-applied status inside raw manifests remain historical provenance. The mapping and source-archive-provenance JSON identify the relocated bytes. Original asset manifests under art-source are archive receipts, not a second runtime asset loader configuration.

Each kind retains its actual current `source/*-master.blend`, original `author_*.py`, texture authoring/checker/tangent tools, `runtime-interface-baseline.json`, original PNG maps, CC0 art declaration, exact project MIT text and DejaVu notice. Bus modelling builds a new body; tram/ferry reuse generic methods from this newly authored bus work while independently constructing their own carriage/hull. They do not export or relabel the old `harbor-vehicle-models.js` body meshes. The original runtime JSON supplies engineering interfaces, door/seat/stair positions and unchanged physics; it is not the original creative mesh. The masters are native editable Blender files with original components/LOD collections/packed maps. This source archive has not opened Blender or independently inspected their native scene contents; original authoring logs and hashes bind them to their delivery. Normal maps are original algorithmic surface maps, not asserted high-poly bakes or photographic scans. The source declarations report no external vehicle model/photo/operator marks.

The retained work-package limits are near <=120,000 triangles, each model <=16 materials, and each vehicle's three GLBs <=12,000,000 bytes decimal. Current totals: bus 11,482,076; tram 9,597,728; ferry 11,660,036. Those byte gates do not establish runtime quality or hardware performance. The original middle-tier target remains 24,000 triangles: bus LOD1 is 24,992 (+992), tram 23,092 (-908), ferry 26,020 (+2,020). The archive does not silently enlarge that target or turn the overages into a performance PASS. Materials and primitive counts are not measured frame cost.

Raw evidence remains under `docs/qa/authored-transport/{kind}/review/`, including current geometry/UV/normal/tangent/index/door ray/headroom/tread/hook results and original Blender/CPU logs. All current reports say CPU_ONLY_NATIVE_REVIEW_PENDING, with current static checks passed and no current geometric issue. These reports do not test the entire passenger capsule continuously, real WASD walking, native door movement/transparent materials/boarding/stairs/seating/save compatibility, multiple-instance GPU ownership, eye-level quality or device performance.

Preserved failures are not rewritten as success: bus `pre-cabin-clearance-fix` has real LOD0/1 stair standing-head obstructions and nonunit tangent issues. That history was explicitly excluded from the bus production deliverable ledger; this supplement includes its actual original bytes with independent hashes and labels the boundary. Ferry `pre-budget-correction` has 136,788 near triangles and 15,251,064 total GLB bytes, failing near-triangle and 12MB total gates; `pre-floor-packing-correction` has 13,313,576 bytes, still failing the 12MB total gate. Both original CPU reports have empty geometric `issues` arrays but false budget/static-check fields: empty issues is not a PASS. Their exact author sources, reports and original logs remain evidence; old failed GLB copies are not embedded here. Tram has no failed-geometry history declared in this delivered package. Native acceptance remains pending for all three.

Licence originals are retained rather than replaced with new licence summaries. Original art declarations dedicate C creative geometry/textures/livery/graphics under CC0-1.0; code/reference data keep the project MIT licence. The copied MIT texts match the ROOT LICENSE byte for byte, and DejaVu notices match the actual local package copyright original. DejaVu is used for rasterized fictional route/instrument glyphs; font binaries are not archived. Its pinned path/hash is recorded as an environment dependency, not as a model source.

Relative authoring inputs are preserved: source tools remain together with author_library.py where used, repair_export_tangents.py, the exact runtime-interface-baseline JSON, and a sibling textures directory. These scripts read inputs relative to `__file__`, while authoring/export/check tools write `models/` and `review/` below the package root. To reproduce later, copy a selected kind into a disposable authoring workspace, retain this layout, provide writable models/review output directories and the recorded Blender/Python NumPy/Pillow/DejaVu environment. Native authoring and checker scripts are not read-only and must not be launched against the archived evidence or frozen ROOT. The editable masters already pack textures; the exact originals are retained separately for editing. Historical failure subtrees preserve original source/report bytes, not a complete independent older GLB payload.

No GLB, runtime source/binding or old prototype source is copied into this supplement. The nine actual current runtime GLBs were only hashed against `/tmp/neon-authored-transport-runtime-candidate/integration-files.json`; their existing `assets/harbor/transport/...` mappings are references in provenance. Bus's old standalone binding is excluded here; the separately reviewed unified runtime candidate owns runtime adoption. No models folder has been duplicated under art-source or QA.

`tools/build.mjs` copies index/styles/favicon/src/vendor/assets; art-source and docs are outside those build entries. Therefore this supplement's editable files, docs and PNG maps are not shipped by that static copy stage. This is path inspection, not a build execution, and does not assert that all PNG files are excluded globally. Native verification and any repo adoption remain root integrator actions after the active tour closes.
