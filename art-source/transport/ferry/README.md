# Lacuna F26 / 澄弧：原创双层港湾小轮候选

独立母模、三档自包含GLB、原创建图和命名挂点已完成；**只有CPU资产检查通过，未接入ROOT、未做原生画面/乘坐/资源/硬件性能验收**。活动D tour仍绑定旧产品，不能作本资产的实录。

新船体由纵向站位与圆润剖面形成带起伏龙骨及收束艏艉的连续曲面。独立制作防擦条、水线带、顺船形变化的栏杆、木质双层沙龙及凹入玻璃、拱形雨棚与原楼梯缺口、环绕玻璃驾驶室、木质曲面座椅与支架、14级楼梯和连续扶手、系船器、救生圈、排气烟囱、桅杆与左右导航灯。采用新母模通用分件方法，船壳与建筑形态均重新制作，不是将旧小轮或巴士改名导出。 名称、线路图、涂装和标记均为原创，无真实运营商、香港地名或商标素材。

source/lacuna-f26-master.blend包含三档原始可编辑分件集合、打包纹理和门编辑关键帧；author_ferry.py保存独立车/船体参数，author_library.py是本次原创母模的通用分件与内饰方法。make_textures.py生成512²PBR表面图、原创木纹和1024×512图形/仪表图集；无外部模型或照片，也未将原创算法法线图写成高模烘焙。源码与方法出处见review/source-provenance.json。
