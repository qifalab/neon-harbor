# Vesper T9 / 曦灯：原创双层街轨车候选

独立母模、三档自包含GLB、原创建图和命名挂点已完成；**只有CPU资产检查通过，未接入ROOT、未做原生画面/乘坐/资源/硬件性能验收**。活动D tour仍绑定旧产品，不能作本资产的实录。

新车体采用回折弧面的车端、带轻微收束的连续侧皮、木质窗柱、凹入双面玻璃及封边。独立制作钢质带轮缘轮组、轮毂与紧固件，轮组位于实际轨道±0.72米；屋顶风箱、绝缘座、连接臂与菱形受电弓顶端4.688米对应现有4.68米接触线。内饰采用新母模方法制作曲面坐垫、弯背、地脚和座后握把、连接扶手、12级踏面/踢面/防滑条/梯梁及驾驶台，而不是导出旧程序车体。 名称、线路图、涂装和标记均为原创，无真实运营商、香港地名或商标素材。
