# Serein D11 / 潮序：原创双层巴士候选

状态：已完成独立母模、三档 GLB、原创建图、命名挂点和渲染绑定候选；**只有 CPU 资产检查通过，未接入 ROOT、未做原生画面/交互/资源/性能验收**。ROOT 与活动 D tour 保持原样。

模型不是旧 `harbor-vehicle-models.js` 网格的格式转换。新制作采用带腰部收束的连续侧皮、复合曲率车鼻、拱顶与车头回折、14–17 毫米玻璃片及凹进封边。灯具分开制作灯桶、镜片和指示灯；轮胎有肩部与胎纹，轮圈有凹盘、通风部位和紧固件；车门有独立滑动叶、封条、把手与连接座。内饰包含曲面坐垫、弯曲椅背、支架、地脚、座后握把、立杆连接、12 级楼梯的踏面/防滑条/踢面/梯梁与连续扶手，以及驾驶台、方向盘、仪表和开关。标志、名称和涂装均为本次原创，无真实运营商、香港地名或商标素材。

可编辑源是 `source/serein-d11-master.blend`，包含三个独立 LOD 集合、原始分件、打包纹理与车门编辑关键帧。`source/author_bus.py` 保留设计截面和所有几何作者参数；`source/make_textures.py` 为原创建图源。纹理512²，标志/仪表图集1024×512。法线图为本次原创表面建图，**不是从高模烘焙或真实摄影提取**。GLB使用可动节点，绑定由游戏实际车门/里程状态驱动；不自行创建班次、乘客或交通逻辑。
