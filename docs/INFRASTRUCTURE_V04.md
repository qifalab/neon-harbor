# v0.4 港城基础设施

此模块补充可以步行、驾车通过的上下层道路和可进入货运码头。尺寸以米计。外观使用共享的世界坐标材质，混凝土、沥青、木条和涂漆金属各有独立粗糙度及表面颗粒；护栏、排水孔、伸缩缝、货柜波纹、门锁杆和候车座椅按真实使用尺度制作。

## 可达地点

| 地点 | 地面入口 | 路线与高度 | 街道衔接 |
|---|---|---|---|
| 西环高架路 | `(-477.2, -1085, 0)` | 沿 `x=-480`，`z=-1080..-600`；两端各 110 米缓坡，桥顶 8 米 | 半山与中环之间的纵向道路；桥下保留东西向街道 |
| 九龙东连接路 | `(-105, -977.2, 0)` | 沿 `z=-980`，`x=-100..620`；两端各 120 米缓坡，桥顶 9 米 | 连接西侧市区与东岸；横跨三条大道 |
| 维湾货运码头 | `(-620, -415, 0)` | 沿 `x=-620` 从 `z=-412` 上坡，`z=-393` 到达 2.4 米甲板 | 抬高入口越过原有 2 米海堤，毋须破坏旧城边界 |

货运码头甲板范围为 `x=-630..-450, z=-382..-308`。西侧通道可一直走到南侧观港座椅，货柜和岸桥留在通道东侧。28 个货柜采用四组涂装、不同堆叠高度，两个岸桥保留框架、控制室、吊索和吊具，防波堤、系缆柱与碰垫组成临海边界。码头位于现有渡轮环线西侧，原有渡轮入口、泊位、航道与时刻表保持有效。

10 个原有交通入口补充售票机、路线牌、垃圾箱、盲道提示、木条座椅和玻璃雨棚。3 个巴士停靠湾设双层巴士、线路牌和候车棚：东岸海滨、中环老城、半山。**此版本巴士为停靠展示车辆，尚未提供乘车服务**；原有地铁、轻轨、城际列车和渡轮继续运行。

## 支持、碰撞与存档约定

`createMetropolisInfrastructure(THREE, scene, { quality })` 返回场景根节点、持久碰撞体、地标、路径元数据、可见距离更新以及销毁方法。关键接口如下。

```js
// currentY 是之前一帧的实际支撑高度，不能换成固定 0。
// 行人使用 groundY；车辆四轮与轮胎修正采样都使用同一个 pose.y。
const support = infrastructure.supportAt(x, z, currentY);
// { height, id, kind, entrance }，或 null（交还原有地面）。
const height = infrastructure.groundHeightAt(x, z, currentY);
```

只接受距上一支撑面不超过 0.7 米的表面。桥下角色继续使用街道路面；桥面角色沿连续坡度移动。两个世界点可以有相同的 `x/z` 和不同的合法支撑层。碰撞查询、车辆支撑缓存、角色移动与相机应使用一致的高度信息。

桥面坡度采用端点一阶导数为零的平滑曲线，视觉路面采用 4 米分段，测试中桥面与解析高度误差不超过 1.1 厘米。斜坡及桥面不作为整块物理阻挡，避免路面自身阻塞车辆；相机保留独立的桥底面。桥墩位于 26 米原车道之外，且避开横街路口，桥上护栏独立处理碰撞。货运坡道采用 1 米分段，以准确跨过海堤。

`supportAt().entrance` 用于将上层道路存档恢复到该地标的安全地面入口。旧存档只记录二维坐标，直接保存桥顶坐标会在加载时落回桥下。`metadata.routes` 给地图提供带高度的路线路径；`metadata.paths` 提供坡脚、桥顶和终点，供体验巡检；`metadata.streetLifeStops` 提供与居民系统共享的三个地面候车活动点。

## 可见距离与性能

静态细节使用局部实例批次。远景保留高架、货柜和岸桥的主体轮廓；波纹、木条、排水孔等细节只在相应地点附近显示。隐藏场景不会移除碰撞，视线或距离变化不会打开墙体。材质与盒体几何共享，公共地表纹理由既有材质系统持有，不重复请求。该模块不更改默认高画质设置。

## 已验证

`node --test tests/metropolis-infrastructure.test.js` 包含八个功能测试：

- 桥下与桥顶同坐标保持两个独立高度，缺省参数不抬升地面角色。
- 两条高架的两端匝道均可双向完整步行，采样路线上无建筑、护栏或桥墩阻挡。
- 四轮车辆双向通过整条高架，没有支撑面跳变或实体碰撞。
- 实际渲染实例矩阵与解析坡度一致。
- 桥下横街保留完整通道。
- 货运坡道连续跨过原有海堤并抵达甲板步道。
- 所有建筑入口、原交通入口以及渡轮航线保持净空。
- 远距离隐藏细节时持久碰撞仍然存在，返回附近恢复可见。

建议正常游戏巡检：在城市地图选择“维湾货运码头”，沿入口正前方进入坡道，穿过门牌后顺着西侧黄线走至海侧座椅；随后前往“西环高架路”，步行或驾车上桥，再从桥下横街通过，观察高度和相机变化。
