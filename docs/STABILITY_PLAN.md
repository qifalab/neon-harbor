# 霓港 v0.2：城市画面、流式世界与驾驶工程计划

状态：本轮实现与本地验收完成；公开发布状态以本次 GitHub Actions 工作流记录为准。基线为 `f8e53f3786ff74a655231672ec837c2355f4df3a`。用户最初反馈驾驶抖动和场景穿模，随后明确目标是精致的城市大作，并要求通过按需加载承载细节。当前范围因此包含驾驶修复、画面重做和实际资源流式加载。长期制作标准见 [美术与世界制作计划](WORLD_PRODUCTION.md)。

## 目标与发布边界

交付可连续驾驶、默认高画质并按街区加载的单机版本。重做车辆曲面、人物比例、近景街道材质和天空反射环境；车辆、角色、相机和场景使用一致的空间规则，新增街区能够自动检查几何和碰撞配置。保留原有驾驶、追捕、三项任务、存档、触屏和 Pages 入口。

本轮同时完成运动插值、跟车镜头、镜头避障、车辆完整轮廓碰撞、动态车辆接触、安全出生与下车、地表高度、城市几何审计及回归测试。完整 AAA 内容量、角色表演、剧情、全面室内场景和多人服务器仍是后续制作工作，不能用模块已搭建来代表这些内容已完成。

## 基线问题与原因

| 问题 | 当前实现 | 修复方向 |
| --- | --- | --- |
| 驾驶时目标与背景抖动 | 物理按 60 Hz 更新，模型直接使用当前物理位置；相机位置平滑，注视点未采用同一时间状态 | 保存前后物理状态，对模型、跟随主体和注视点统一插值 |
| 路边镜头突然缩短 | 用二维采样查询全部障碍，无视长椅、灯杆、屋顶的实际高度 | 带高度和安全半径的连续镜头阻挡查询，立即避障、平缓恢复 |
| 相机绕角穿墙 | 只检查期望镜头射线，平滑后的实际位置仍可能穿过墙角 | 检查最终相机位置、视线和移动路径，覆盖近裁剪面 |
| 车头与车尾进入障碍 | 约 2.29 × 4.56 米的可见车身仅使用半径 1.55 米的碰撞圆 | 所有车辆共用覆盖可见车身的有向矩形，平移和转向都检查碰撞 |
| 撞墙反复震动 | X/Z 分开拒绝移动，碰撞后将速度反向 | 按接触法线消除朝墙速度并沿墙滑动，分离阻挡与损伤计时 |
| 车辆互相重叠 | 距离判定只处理损伤，冷却期间不检查接触 | 动态车辆始终参与实体阻挡，损伤仍使用冷却 |
| 脚部或车轮埋入路面 | 模型统一放在 y=0，人行道、公园和木栈道有不同高度 | 世界输出地表高度，角色、车辆和氛围行人统一采样 |
| 道路与装饰闪烁 | 路口由极小高度差的重叠道路组成 | 路段与路口不重叠，标线和地表保持明确层次 |

## 模块与数据契约

| 模块 | 职责 | 不应承担的职责 |
| --- | --- | --- |
| `simulation.js` | 玩家/车辆权威状态，驾驶、交通、追捕、任务、经济和存档 | 相机和 DOM |
| `collision.js` | 共享实体尺寸、空间索引、形状相交、连续小步运动与接触法线 | 渲染和奖励逻辑 |
| `world.js` | 原创场景、障碍物高度、可行走地表、氛围行人路径 | 单独维护一份与实际模型不符的物理尺寸 |
| `models.js` | 曲面车身、车轮和人物模型，共用物理尺寸 | 私有化另一套轮胎或车身坐标 |
| `atmosphere.js` | 天空、云层、PBR 反射环境和统一光色 | 更改游戏时间或车辆状态 |
| 世界加载模块与 `tools/build-city.mjs` | 离线生成街区数据，运行时请求、预取、装配与回收 | 预建全部细节后只切换可见性 |
| `presentation.js` | 前后物理快照、角度最短弧插值、状态跳变重置 | 修改游戏规则状态 |
| `frame-clock.js` | 60 Hz 固定步、有界时间补算、暂停与失焦时基重置 | 把几秒卡顿转换成一次巨大物理位移 |
| `camera.js` | 跟随、转向、视野、镜头阻挡与恢复 | 直接推进车辆运动 |
| `main.js` | 输入、生命周期、上述模块接线、HUD 和只读诊断 | 再复制一套碰撞规则 |

约定世界单位为米，Y 向上，yaw=0 面向 +Z。静态碰撞体至少包含稳定 `id`、`x/z` 中心、`hx/hz` 半尺寸及 `minY/maxY`；相机可使用独立的高处遮挡体。地表描述与可见几何来自同一生成过程。车辆的物理轮廓覆盖车头、车尾和后视镜。保存格式继续兼容 v1，导入位置必须经过当前世界安全检查。

一帧的数据流为输入采样 → 固定物理步 → 保存状态快照 → 插值呈现 → 跟随与相机碰撞 → 绘制。暂停、失焦、重生、导入、重置和上下车都必须有明确的状态过渡，禁止相机沿上一目标的长距离路径缓慢追赶新目标。

## 分阶段实施

### A：定位与契约

- [x] 核对线上提交，审查物理尺寸、相机、道路层次和动态碰撞。
- [x] 明确模块分工、统一空间坐标、静态阻挡与地表高度契约。
- [x] 建立能复现车头穿墙、转向扫墙、碰撞反弹与镜头墙角问题的回归案例。

### B：运动与镜头

- [x] 固定步快照与渲染插值，所有活动车辆和人物使用相同时间基准。
- [x] 跟车位置、注视点、朝向、距离及 FOV 稳定过渡，角度跨 ±π 连续。
- [x] 连续镜头避障，处理墙角、窄巷、低矮障碍和近裁剪面。
- [x] 暂停/继续、重生、导入、上下车及手动环顾后的恢复不产生长距离甩镜头。

### C：碰撞与世界

- [x] 车辆完整有向轮廓、扫掠平移/旋转、边界和窄障碍防穿透。
- [x] 玩家车、交通车和警车的持续实体接触，稳定沿墙滑动及损伤冷却。
- [x] 出生、车辆生成、救援和上下车位置安全检查，不能从墙的一侧穿到另一侧。
- [x] 地表高度与模型落地一致，道路交叉不叠面。
- [x] 场景实物与阻挡元数据审计，修正可见几何交叉及行人路径。

### D：画面与流式世界

- [x] 重做车身曲面、玻璃、轮圈、灯具和内饰，车轮尺寸与接地点使用物理共享配置。
- [x] 重做人物比例、头部、服装和可关节动画，替换方块形体。
- [x] 加入天空、云层、环境反射和统一曝光，默认精细画质，不自动降低近景质量。
- [x] 建筑近景加入橱窗、门框、檐棚、立面和屋顶细节，道路使用可重复的材质细节。
- [x] 构建时生成街区资源，运行时真实 HTTP 加载；附近区域就绪后进入，行驶方向预取。
- [x] 远景保留天际线，离开区域回收详细实例与缓存；失败可重试，碰撞始终可用。
- [x] 默认高画质截图检查，并实驾跨街区验证请求、回收与附近区域完整性。
- [x] 近景保留完整车/人，按镜头距离选择模型层级，灯光阴影不能把近景切为远景模型。
- [x] 4–144 Hz 下固定步时钟保持正确模拟时间；长卡顿有明确步数上限，暂停/隐藏不补算。

### E：整合与审查

- [x] 运行物理和相机纯逻辑测试，在 30/60/90/144 Hz 及不均匀帧间隔下核对连续性。
- [x] 保留三项任务的实际城市输入驾驶验证，不通过传送或关闭碰撞获得成功。
- [x] 浏览器从正常出生点步行、上车、加速、转向、接触障碍、停车和下车；检查只读状态、画面和控制台。
- [x] 检查暂停、恢复、存档导入、触屏和 WebGL 初始化既有流程。
- [x] 独立审查几何/物理接口、热点查询、实体删除和状态切换；记录实测结果及限制。

### F：发布

代码、版本、README 和验收记录一并提交。GitHub Pages 工作流为每次发布执行以下门禁，实际状态与日志保留在 Actions：

1. 针对选定提交运行完整规则测试、资源生成、构建与浏览器回归。
2. 仅在门禁通过后部署该提交的静态产物。
3. 访问实际公开网址，核对提交、已加载文件摘要、WebGL、街区和交互，留存高画质截图与报告。

## 验收矩阵

| 场景 | 必须成立的结果 | 证据 |
| --- | --- | --- |
| 匀速、加速、转弯、反向转向 | 模型与相机使用同一插值主体，角度跨界不绕大圈，结果有限且连续 | 多帧率确定性测试、浏览器驾驶采样 |
| 高速正撞、斜撞、擦墙、窄杆、原地扫角 | 车辆完整轮廓不穿透，接触后不反复正负反弹 | 带法线的接触测试、完整车身相交断言 |
| 车车相遇、追捕接触、连续顶住 | 冷却只影响伤害，不能解除物理阻挡 | 动态接触回归 |
| 建筑后侧、转角、矮墙、棚檐 | 镜头最终位置和近裁剪范围不进入障碍；避障后平稳放长 | 三维射线/体积测试、浏览器画面 |
| 路口、人行道、公园、栈道 | 不存在重叠道路大面；脚部和车轮处于对应地表 | 世界生成审计、地表采样测试 |
| 贴墙上下车、导入非法位置、救援 | 有安全位置时恢复，无安全出口时明确拒绝，不能隔墙上下车 | 规则测试及可见操作回归 |
| 三项任务 | 继续通过实际世界驾驶输入完成且奖励规则不变 | 原有整合测试 |
| 默认画面 | 高画质启动，曲面车辆、人物、材质和天空反射可见 | 同位置实机截图，几何尺寸审计 |
| 街区加载 | 初始附近完整；行驶发生新请求；离开回收；近处无空街区 | 真实响应内容、居民资源统计与跨区浏览器测试 |
| 线上站点 | 所有模块加载成功、WebGL 可启动、主要菜单可用 | Pages 部署后报告与截图 |

纯逻辑测试使用小误差容限，覆盖完整轮廓及中间运动状态；浏览器不使用可变调试接口替代玩家输入。帧率测试验证时间处理与呈现连续性，不等于承诺某一设备能跑到相同帧率。真实显卡、Safari、Firefox 与手机兼容性仍单列为设备矩阵，不能用 CI 软件渲染结果替代。
