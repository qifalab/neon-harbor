## 初轮失败与修正范围

初轮保留的三项失败见 [错误摘要](initial-failures.json) 和 `initial-failures/` 中的完整 trace、错误上下文与可用失败截图。没有覆盖或删除失败结果。

海港与三岸目录检查使用旧 ID 前缀筛选北岸，误排除了北岸的 `east-quay-hotel`，得到 47/48；复核使用分区字段，并保留 48 北岸、96 南岸、76 东湾和总计 220 的断言。渡轮初轮在离站的 60 秒墙钟期限超时；CI 允许 180 秒离站等待及 600 秒全场景时间，游戏时钟未加速，原有等车模拟时间 `< 17 秒`、离站 `< 11 秒`、行驶中不能下船及真实到岸检查均保留。移动测试使用本次服务器的 `baseURL`，并实际检查五个动作按钮的边界。

复核使用真实浏览器时钟和公开键盘、触摸、菜单及城市导览操作，Playwright 自动重试为 0。v0.8 的公开导览仍会定位到所选入口；这些场景不是新海港样板要求的 20 分钟连续、无传送生活路线。

## 实际画面与局限

`city-materials-supplement/` 保存旧城二楼房间、东湾封闭办公室与东湾观景露台的三张 High 游戏截图、机位和 WebGL 状态。它们通过真实房门、窄实体楼梯或电梯到达，旧城使用公开 Z 精准慢走；退出、外壳恢复、重新进入和东湾安全重载由对应测试检查。三张图均为 640×400、16:30 的实际渲染画面，新增南岸 / 东湾房间没有本次同机位 v0.7 对照。

`five-rechecks/` 保存默认 High 昼夜海港、移动布局、驾驶、地图和渡轮等实际画面。`original-regression/` 保存真实居民进入工作房间的实际截图，居民场景为 Low、512×320；它提供生活路径的功能证据，不替代 High 美术审查。

已打开检查的图片与具体观察见 [visual-review.json](visual-review.json)。样本未见黑屏或明显像素边界条纹；共享室内、简单家具、程序立面重复及粗略远景仍可见。静帧不能证明移动镜头没有闪烁，也不代表逐房精修或 3A 制作完成。

全部运行使用 Linux Chromium 的 ANGLE SwiftShader 软件 WebGL。时长是功能场景执行耗时，不能推导桌面独显、集显或移动设备 FPS。真实硬件性能、完整兼容性与逐房美术审查仍待独立验收。这些证据覆盖 v0.8 基线，未验证新海港样板的三种双层交通、正式 GLB 资产或居民商业经济闭环。
