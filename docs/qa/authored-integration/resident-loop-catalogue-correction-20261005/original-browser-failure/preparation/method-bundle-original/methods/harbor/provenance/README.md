# Prepared High native method — not executed

This package prepares the next original-pixel art inspection. No browser, GPU,
server or build was run while producing it. No repository or integration source
was edited. The only executed checks were syntax/plan compilation, three
single-floor layout calculations, one home stair clearance tube and four small
CPU checks of input/error recording.

Run **only after the parent closes the frozen tour, accepts the built runtime
and explicitly issues the next GPU GO**. Start the independent tool with cwd
at the actual `/workspace/scratch/neon-harbor` Git root. It serves only that
root's `dist`, resolves Playwright from that root, reads the real current Git
HEAD/status and copies the full exact manifest asset dictionary. Historical
catalogue D is a coordinate source, never a fabricated runtime revision.

Choose one case per process, serially. Every output must be a new empty
directory outside the repository. Never add an automatic rerun loop after a

asset/owner expectations only. `plans.mjs` is one shared route/camera definition.
