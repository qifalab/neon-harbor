# Six actual near-quay tree candidates

This isolated candidate replaces only six existing street trees seen along the actual High resident shot from the tide-museum pavement. The tree owners are tide-museum, harbor-market and ferry-house; x=-617/-503/-457/-343/-297/-183, z=-445. The original three render instances per tree, all original collision, original procedural export and every north chunk JSON byte are preserved. There are 96 general streetscape trees before this revision; the other 90 plus other decorative vegetation remain unchanged. South palms/park trees and mountains are outside this candidate.

Three original editable metric GLBs have real tapered curved trunks, six primary forks, eighteen smaller branches and 576 separate folded closed thin leaves each. The leaves have two real surfaces and 1.6mm thickness, vertex color variation and original varying roughness maps. Bark has original ridged albedo and roughness images. No canopy sphere or external tree asset was used. Original recipes, geometry generator, pixel-image generator and CC0 waiver are supplied. `asset-manifest.json` binds the actual GLBs and source bytes.

The owner loads only templates needed inside 80m and retains them until 100m. It masks only the selected original trunk/two-crown instances after real GLBs have arrived; pending/error/far/Low/unload restores the exact old instance matrices. Templates are owned by their original streamed chunk attachment, late loads are invalidated and disposed, entering the source building hides its tree as the old shell owner did, and Low releases authored templates before High can load them again. Node export retains the original world and never loads models unless the CPU test explicitly injects the loader.

Three template variants use two-material InstancedMesh batches, with two instance slots each. The actual maximum observed CPU submitted count is 6 added draw /53,664 added triangles, including zero-scale slots. Each tree is 8,944 triangles; no default quality was reduced. The full Canvas-dependent label branches were enabled in the world comparison; their pixel painting and texture bitmap decoding are CPU placeholders, not a renderer or native ImageBitmap measurement.

Actual CPU checks decode exported GLB bytes rather than reading only recipes: 1,728 closed leaf solids have outward nondegenerate triangles and real thickness, all low trunk vertices remain within the old 0.35m half width, and 72 primary/twig roots have odd ray intersections within the corresponding actual closed parent mesh. A first curve-to-straight-line branch attachment draft was preserved and then corrected to the actual curve before these triangle containment checks. All current tree meshes stay within the old metric AABB. The old world export/colliders and all old far instance matrices match exactly. The actual DistrictStreamer loads two source JSON files, unloads over twenty finite 0.2s simulation frames, clears residents, then reloads at the same position. Material/texture/geometry disposal, CPU bitmap-owner close, cancellation, stale-template disposal and interior/quality restoration are recorded. None of these observations is a GPU or memory measurement.

Only the tree version of `src/metropolis-world.js` and the new `src/harbor-sample-trees.js` change runtime source. Root must merge `world-hook-only.patch` additively beside the independent mountain agent's buildBatches change; this candidate leaves that InstancedMesh constructor/loop unchanged. All new asset/source dictionary entries and affected method-proof amendments must be generated from that final combined build. Historical proof bytes and old capture dictionaries remain historical.

The old actual native PNG/metadata, old world source and original chunk hash inventory are preserved. The former original capture was a failed resident-core run, not acceptance. Its pixels motivated the work and cannot approve this new source. New High same-position views near the original resident camera and at one trunk/leaf close distance are still required; root will perform them. No ROOT, 6ad frozen candidate, HEAD, GPU or network was modified.

Mid-development JSON/old-envelope mistakes and CPU fixture/driver failures are preserved under history. Final raw CPU results are separate. The missing north JSON files were copied unchanged from ROOT into the isolated CPU fixture only; no chunk generator or production chunk was changed.
