# 港湾近树冠密度审查

当前 `5cd20885881c5fd9d30b405eb267a25ec7752164` 的近树不能作为亚热带港湾街景的美术通过。实际 High 原图中，旧球冠已替换为真实弯干、枝条和叶片，但大部分冠体透空，枝线比叶冠更明显，呈稀疏冬冠。这个结论来自原始 PNG 目视检查，不是模型数量判断。

实际检查的图片是 `5cd-resident-core-11326827515/extracted/native/authored/02-commuter-player.png`，SHA-256 `dbe6da212cc1d32598418040ad1cab116a1cfc3c477150018f116d3c90d9dcb0`。同时检查同目录 baseline 图。两图时间均为 16:30、High、1280×800；人物和当次自然位置不同，不能做逐像素差异归因。

## 原模型为何显得稀疏

原来每树 6 条主枝、每枝 3 个末端 fan、每 fan 32 片闭合薄叶，总共 576 片。fan 的叶中心都挤在末端约 0.46–0.48 米半径小盘里，主枝中段、冠内和中层没有叶冠层次。

读取实际 GLB 的每片叶首两片三角形，得到单面折叶总面积 18.22–18.34 平方米。这是所有叶片的面积和，并不等于可见冠覆盖率。5 毫米采样的正视三角形投影并集只有 2.63–2.75 平方米，除以相同模型叶冠凸包的 17.60–19.15 平方米，为 14.3–14.9%。侧视为 15.4–19.1%，顶视为 21.3–22.4%。

实际 commuter 摄影机前方的 B 树在几何投影里，冠顶叶区只有约 59×42 像素。每叶投影包围盒中位值约 2.44×1.20 像素；576 片叶里有 219 片的短边不足 1 像素。抗锯齿、暗色叶材质和场景遮挡会进一步影响原生画面的可读性，不能用这个 CPU 几何投影代替 native 渲染。

当前每叶原形长 0.29–0.43 米、宽 0.13–0.21 米，已经偏大；直接扩大叶片会产生纸牌叶与比例问题。补冠内、中层和枝段之间的多层簇更合适。

## 最小密冠候选

候选位于独立 `tree-crown-density-candidate-20261005/payload`，未写入生产工作区，未启动 GPU。

每树保留原 576 叶和完整树皮几何，用独立随机源增加 1,152 片同尺寸的闭合叶：沿 6 条原弯枝的 6 段分布三维簇，覆盖原枝 36%–95% 段，补入冠内及中层。不是新球冠、贴片罩或 alpha cutout。

| 每树闭合叶 | 576 | 1,728 |
| 每树三角形 | 8,944 | 22,768 |
| 六树最大提交三角形 | 53,664 | 136,608 |

| 顶视冠凸包覆盖率 | 21.3–22.4% | 49.9–50.8% |

增加的三个 GLB 共 5,475,832 字节，约 5.22 MiB。两材质、两网格和三个 variant 的 instanced owner 不变，所以全量仍为六个新增 draw。实际 owner 每 variant 有两实例槽，即使某槽为零缩放，提交统计仍包括它；预算是最大提交量，不是“每个可见树”估算。

本次独立检查逐属性比较了新旧三棵树的 bark POSITION、NORMAL、TEXCOORD_0、COLOR_0 字节 SHA，全部相同。新叶位置仍在原 AABB `[-3.4,0.3,-3.4]` 到 `[4.5,12,3.4]` 内；枝根、低干和原 collider 几何不应因密冠变化而改变。原 72 个实际父三角形内部根点检查、每叶闭合厚度、非退化、运行时唯一预算常量差异由候选作者另行提供，不在本独立投影报告里冒认重跑通过。

采用时必须显式更新原 runtime 的每树 9,000 / 六树 54,000 上限；建议每树 25,000、全量 150,000，原 80 米加载、100 米恢复、站点、chunk ownership、Low 释放和进入建筑隐藏等接口保持原字节。增加约 2.55 倍近树三角形和 5.22 MiB 资源是明确代价，需要真实 High 图与释放检查后决定。

## 验收边界

新候选的 CPU 投影并集显著增加，能解释为什么值得原生 recapture；它还没有 GPU 美术通过。须在相同 16:30、High、实际摄影机下检查整体树冠、近叶比例与厚度、树干与枝连接、自然空隙和阴影，观察近远恢复及 Low→High，再决定是否采用。CPU 曲面面积、闭合三角形和预算通过都不能替代这一步。

当前六棵样板近树外的植被仍沿用旧模型；实际同一街景里仍可看到远处球冠。不能宣称全城树木都已达到相同品质，也不能把新候选占冠密度改进称作 AAA 验收。

机器结果为 `measurement.json`（实际原 5cd GLB）和 `candidate-measurement.json`（独立候选 GLB，使用实际旧摄像机做 CPU 几何投影）。所有投影结果仅为几何测量，不包含深度遮挡、纹理、抗锯齿或实际光照后的像素覆盖。
