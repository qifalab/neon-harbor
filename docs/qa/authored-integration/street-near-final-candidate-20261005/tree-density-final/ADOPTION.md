# Original near-quay crown density candidate

This is an isolated, reproducible **CPU-validated candidate awaiting actual High browser art and performance review**. It does not approve the harbour's art. No ROOT / NEXT source, build, Git state, native method or original seal was modified. No GPU or browser was started.

The original sparse model placed all 576 leaves in 18 terminal discs. Each candidate retains those original leaf attributes exactly and adds 1,152 same-size closed leaf blades using an independent random stream *after* all original geometry. The additions occupy six three-dimensional clusters along each original curved branch from 36% through 95% of its length. Inner and middle crown levels are populated; branch systems still have open gaps. No sphere crowns, alpha planes, enlarged leaf cards or new bark are introduced.

Ship only the **13 regular files listed by `payload-ledger.json` under `payload/`**. Do not copy this directory's execution symlinks or CPU helpers. The runtime change is exactly `maxTriangles:54000,maxTreeTriangles:9000` → `maxTriangles:150000,maxTreeTriangles:25000`; sites, 80 / 100 m thresholds, owner / cancellation / release functions and all remaining runtime bytes are identical. `runtime-budget-only.patch` records that sole runtime change. The existing world hook is reused.

All three variants contain 1,728 leaves, 2,032 original bark triangles and 20,736 leaf triangles: **22,768 triangles per tree**. All three variant templates have 9,580,552 raw GLB bytes and 9,016,128 decoded Float32 attribute bytes. The maximum visible three-variant instanced submission is **6 draws / 136,608 triangles**, counting both instance slots per variant. This is 82,944 more submitted triangles and 5,475,832 more raw GLB bytes than the sparse model. These are CPU byte and submission counts, not hardware VRAM or frame-time measurements.

The declared metric envelope remains `[-3.4, 0.3, -3.4]` → `[4.5, 12, 3.4]`. All emitted positions remain inside it. Tight leaf bounds extend lower inside that envelope to populate the middle crown; bark bounds and original root geometry are unchanged. POSITION, NORMAL, UV and COLOR bark arrays match original SHA-256 values exactly. The first 576 leaves' POSITION, NORMAL, UV and COLOR arrays also match the original attributes exactly. All three original CC0 embedded textures are byte-identical.

`cpu-density-proof.json` measures all actual emitted triangles: each leaf has eight unique vertices, eighteen manifold edges and twelve nondegenerate triangles, with oppositely oriented edge pairs, nonzero enclosed volume and actual transformed thickness of about 1.6 mm. Total closed surface area includes both faces and the thin edges; single top-face area is reported separately. `cpu-real-branch-attachment-proof.json` re-runs all **72 actual-parent-triangle containment checks** against the candidate bark. `cpu-owner-density-proof.json` validates 80 / 100 m loading and release, exact far matrices, room hide / restore, Balanced / Low / High, chunk unload / reload and cancelled late loads with the real decoded candidate geometry. Its image-close counters use CPU stand-ins; native image closure is unproven.

The asset manifest pins all seven editable source files and the three final GLBs. `reproduction-proof.json` shows a second author run produced identical hashes for every payload file. Running the shipped author source requires the repository's vendored Three.js at `vendor/three/`; that dependency is read-only and is not duplicated into this payload.
