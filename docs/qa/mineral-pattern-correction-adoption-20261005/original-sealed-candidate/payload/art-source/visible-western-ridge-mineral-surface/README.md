# Western ridge dry mineral surface source

This original CPU-authored material candidate addresses the broad smooth grey-green, soft-clay surface seen in the closed b80 daylight originals. It does not change the existing connected mountain shape or declare photoreal/AAA acceptance.

The editable recipe lives in `src/metropolis-western-ridge.js`: seed 2026100521 creates 40 unequal periodic stone cells across a 16m sheet. Shallow irregular fractured margins and small unequal stone offsets produce two inline 128×128 RGBA8 standard PBR maps. Normal and roughness maps use no colour space, repeat wrapping, linear mip filtering and generated mips. The standard Three roughness shader consumes the actual green channel, multiplied by material roughness 1. The West material has no custom shader hook; the shared surface-finish module and every other material retain their original hooks.

Map texels span 12.5cm in world UVs. At the actual roughly 300m harbour cameras, the irregular 0.8–4m surface structures can affect a few pixels; microscopic pores cannot be resolved reliably. Slope, drainage and height masks therefore also separate darker planted slopes, warmer soil, exposed stone and nonperiodic 17–41m mineral/planting patches in the existing vertex colours. This macro layer is intended to survive mip filtering; normal maps do not add silhouette relief or a displacement mesh.

West position, normals, indices and bounding envelope are preserved literally from b80: 4018 vertices, 8032 triangles, one draw. The unused West mountainSurface shader attribute is replaced by standard UV with the same two-float storage. Top UV is world XZ /16m; only below-ground closed-skirt UVs are radially expanded by 0.6% to avoid degenerate side triangles. No collision, entry, support, streaming, lighting, global postprocessing, or other model source changes are part of this candidate. The minimal North adapter copies these West UVs and preserves all actual North geometry attributes, standard-material inputs and original two 256² map pixels.

The West geometry and material owners have idempotent disposal; material disposal releases each inline texture exactly once. Temporary height/fracture arrays used during map creation are not retained by the material. Conservatively counting both retained CPU pixels (131072 B) and complete GPU mip pyramids (174760 B), additional texture memory is theoretically 305832 B, below 0.5 MiB. This is derived accounting, not measured GPU VRAM. West geometry bytes stay 224984 B and original producer arrays/scratch stay 283472 B, below the unchanged 300000 B cap.

No image has been edited or generated to serve as visual acceptance. Final native Day/Night comparisons and the final source regression run for this correction are pending adoption by the root agent.

The actual 9cf High harbour frame showed a woven/checker-like highlight pattern on the West mountain. Surface recipe v2 removes every coherent sine component from the mineral height field (previous strata, sheet and grain) and from roughness. It retains unequal Voronoi fracture margins and subtle stone-height offsets, and reduces the standard tangent normal scale from 1 to 0.35. Existing terrain vertex colours now use nonperiodic smoothed hashed patches at 17, 28, 37 and 41m scales, with less dark mineral mixing. This targets the actual repeated-highlight defect without changing geometry, UV, lights or display quality. The earlier native image and failed art judgement remain preserved; this candidate has no pixel acceptance yet.
