# v0.4 街区居民与日常生活

每个北城地址保留五位逻辑居民，共 240 位。居民的姓名、职业、衣着、身形和活动进度独立于渲染实例，走远再回来不会重新抽一批人。姓名组合有 240 个独立结果，六区合计有 30 种职业。

时段分别为 06:00–11:00、11:00–15:00、15:00–20:00、20:00–06:00。变更时段会改变目的、活动与步速，居民必须实际走到下一个活动点。每次停留 9–27 秒；街边短程通常 30–62 米。原先每栋两位永远站在原地的人，现在会结束聊天、分开活动，并在后续行程回到楼前约见点。

活动包括阅读、工作记录、查看交通时刻、饮茶、摄影、采购检查、舒展、休息和对话。对话需要身边有其他居民，失去谈话伙伴时会转为读书。时间、动作与位置遵守游戏暂停。

## 视觉实现

继续使用原有平滑曲面人体、面部和八个关节，不改变近处人体精度。新增宽窄体型、身高差异、老年步速和轻微身体前倾。不同活动有独立手臂和手肘姿势，行走含摆臂、膝盖弯曲、微弱身体起伏。

职业道具包含书册、手机、饮料、相机、采购纸箱与工具袋，细框眼镜和棉质工作帽进一步区分人物。道具随手肘骨骼移动，三个距离层级均有一致的手持关系。道具几何和材质按模板共享，不给每位居民复制 GPU 资源。

预算保持 240 位逻辑居民、最多 32 位关节完整的近处居民、112 位远处实例，每帧最多生成两位近处居民。原有空间索引、车辆让行与居民避让继续生效。

## 交互与边界

接近后提示明确显示姓名和职业。连续交谈四次会依次给出身份与当前目的、当地生活事件、该建筑真实开放楼层、街区生活描述。方向目标始终指向该建筑实际入口，楼层文字读取建筑目录。

普通居民的步行目的地均在经过碰撞验证的本街区人行道闭环上。通过 `streetStops` 接入基础设施的三个巴士停靠湾，每站从邻近地址调配一位既有居民，人口总数保持 240。他们在真实雨棚前查看线路、等待同行的人，并在外侧人行道短程走动。东、西侧候车线位于 x=±654.8，避开 x=±640 的机动车道、停靠巴士、座椅与雨棚柱。

目前没有让居民实际乘坐列车、轮渡或静态展示巴士。没有自动跨越机动车道，也没有为了到达目的地瞬移到马路另一边。跨区通勤需要后续以实际过街设施与站点人行连接为基础实现。

## 验证

`node --test tests/metropolis-people.test.js` 共 12 项通过，覆盖：

- 48 条人行道线路避开所有建筑与机动车道。
- 240 个稳定身份、30 种职业、六区四时段生活内容。
- 有限活动停留、社交居民重新出发、日程变化不会瞬移。
- 暂停冻结、车辆阻挡让行、人数预算与远离城市后的卸载。
- 地方性对话、真实楼层指引、附着于手的共享道具和 LOD 关节同步。
- 移动后的空间查询正确性与资源释放幂等。
- 三处实际巴士停靠湾的居民数量、活动、车辆避让和不跨越机动车道的候车线路。

固定中午、模拟 120 秒的验证中，237 位居民至少推进一次活动，193 位居民离开初始位置超过四米。该数据是行为正确性检查，不是 GPU 帧率测量。
