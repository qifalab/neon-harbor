# 北岸逐栋制作档案

所有地址、入口与楼层由 `src/metropolis-catalog.js` 驱动。每栋开放三处公共空间；表中层高为游戏世界实际米数。自动几何验收覆盖48栋入口与144层家具/墙体，人工画面检查采取代表性地点抽查，不把未逐栋人工试玩的内容标成已逐栋完成美术验收。
