# v0.4 公共楼层室内设计

本次逐地址重做 48 栋建筑的 144 个公共楼层。每层有 4 个明确命名、可从中轴进入的功能分区，共 576 个分区，使用 66 种具有专属陈设的功能类型。分区不等于独立封闭房间；住宅、诊疗、实验等需要隔离的分区有隔墙与真实门洞，展馆、餐饮、观景空间主要采用开放布局。未建模的普通办公层和私人住宅层不在这 144 层范围内。

## 设计与实现

- 唯一设计表为 `src/metropolis-room-designs.js`。每个地址分别写明公共门厅、公共活动层、屋顶/观景层的名称、用途、四区名称与摆设类型。没有将建筑名更换后重复同一套四区用途。
- `createInteriorLayout` 的 `design`、`rooms` 元数据和实际陈设使用同一设计表。每区包含入口坐标、门内净空点、范围及 `enclosed`；界面可以直接展示真实用途。
- 住宅按实际生活尺度围合：起居 9×10m、卧室 8×8m、厨房 7×8m、浴室 5×6m，净高 2.98m；社区公共会客室 14×14m，设置多组座席。以真实墙体围合未开放外围，避免大空间中央孤立一张床。
- 家庭住宅分为起居、卧室、厨房、洗浴四区；医院有分诊、诊室、药房、观察病房、康复器械；音乐学院有钢琴、弦乐、打击乐与监听室；海事博物馆有船体、帆桅、航标与档案；学校、电影院、工坊、银行、菜市、邮局、研究院等按实际功能陈设。
- 生活物件包括碗碟杯具、食物、书报、灯具、布面软垫、床品、毛巾、行李轮子、信箱、衣架、乐谱、工具、实验容器等。圆角箱体、圆柱、球面与箱体按材质和形状合批，避免每个小件单独 draw call。
- 文化展厅、剧院、车站和银行公共大堂使用哑光石材大板地面，湿区保留瓷砖。海事博物馆门内增设近景迎宾船模和系泊锚，通道净宽不变。
- 座椅、布料、白瓷、金属与木材使用共享的真实贴图材质；每次只组装当前公共楼层。圆角/曲面使用与渲染外包围尺寸一致的保守 AABB 碰撞体。
- 中轴至少保留 8 米通行宽度，封闭功能区门洞净宽 3.2 米，真实电梯机位和出入口坐标保持兼容。EXIT 标识缩小并移到门侧；入口盆栽改用圆盆与非方块树冠。

## 验证
