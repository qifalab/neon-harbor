## 全城尺度与扩展路径

后续制作具有香港式密度、坡地、海湾和外岛气质的原创城市，使用原创地名与商号，按可玩街区逐步连接城区、山地和离岛，没有 1:1 全香港测绘承诺。当前 X/Z ±1,800 米是 **3.6 公里 × 3.6 公里的位置验证包围范围**，不是已制作的 12.96 平方公里；220 栋 / 4,150 层共享布局也不是全城精修成果。

依赖顺序为：新源功能 / 交通实际复验与完整外观取证 → 港湾车辆、山树街灯、室内和人物必修精修 → 已接入的港湾共同日历与三职业增量进行原生逐人跟随 / 动作 / 恢复验收，再扩大剩余居民覆盖→ 完整港湾交付 → 旧城 / 山城及跨区交通 → 中城 / 新区 / 工业岸与外岛。完成依据是每区实际路线、原生画面、恢复一致性和目标硬件测量，不预填日期、人天或未实测的人口成绩。

长期采用全局区域 ID 与区内米制坐标、渲染浮动原点、远景 HLOD、按需街景 / 室内楼层与邻近物理。正在使用的地面、楼板、桥和登乘支撑不得因卸载细节而消失；远区居民在同一权威时钟下低频推进，回到近处升细，工作与库存不因出区重置。区域、路线、存档或多人 `worldId` 迁移前先保留可恢复旧存档，并验证映射与兼容性；世界扩展不能只调大坐标上限。这些是后续架构要求，不宣称当前已实现。

当前维持 Web / Pages 的可分享客户端。先测量真实设备的 CPU / GPU、FPS / 帧时间与驻留，再决定 WebGPU、独立客户端或引擎迁移；Three.js 与 Pages 不代表已有商业 3A 能力。技术迁移仍须保存同一世界数据、存档、交通、居民和有限经济及既有功能。完整区域与架构依赖见 [全城制作计划](WORLD_SIMULATOR_PLAN.md#全城尺度与扩展路径)。

## 制作目标

1. 区分车漆、皮肤、衣料、皮革、金属和矿物表面的微细节与粗糙度，适量增加近景衣物及软装形变。车辆、人物与家具须分别近看；规则测试或材质参数变化不替代实际画面判断。
2. 在天空环境中加入按实际建筑位置、尺寸和基座生成的近邻代理，按距离与昼夜变化更新。代理用于近似环境反射，不声称实现实时街景反射、SSR 或平面反射。
3. 精细、均衡画质加入深度重建、半分辨率遮蔽与深度感知合成。检查色彩输出、抗锯齿、闪烁、黑屏、轮廓脏边、尺寸改变和资源释放；流畅模式保留直接渲染路径。默认画质保持精细。
4. 旧城小楼使用两房、中央通路、窄实体楼梯与后部电梯；东湾采用四房间用途布局。楼梯穿过真实楼板开口，家具须避开入口、房门、楼梯与电梯路径。入口筛选须进入目标建筑，离开与重载后须恢复外壳。
5. 每栋开放楼层连续，室内最多保留相邻三个精细楼层。外部街区与建筑细节继续按距离加载、释放；保留地面支撑和碰撞，不能用降低默认画质替代资源管理。
6. 保留分车道交通、圆滑转弯、跟车减速、路口放行与出口避堵，回归地铁、渡轮、连续楼梯、电梯和北岸居民路径。新增两岸暂不扩展 240 名北岸居民的住处和工作网络。
7. 客户端与独立多人服务共同使用 `neon-harbor-v08`，支持 8 人房间、玩家、共用车辆与聊天同步，位置范围为 X/Z ±1,800 米、高度上限 460 米。双浏览器需覆盖新区域和高层；GitHub Pages 只发布单人默认客户端，公网多人后端另行部署。
