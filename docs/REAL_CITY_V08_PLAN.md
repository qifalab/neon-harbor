# Neon Harbor v0.8 · 三岸基础与港湾生活样板

更新日期：2026-10-04。实施与验收分开记录；最终结果以 [QA_V08.md](QA_V08.md) 及线上 `build-info.json` 为准。

用户选定的首轮交付为完整港湾样板：高品质街景方向、双层巴士、经典小轮、双层街头电车与居民日常。全城世界模拟器的分区、资产、资源和经济路线见 [WORLD_SIMULATOR_PLAN.md](WORLD_SIMULATOR_PLAN.md)，连续路线及画面 / 性能门槛见 [HARBOR_SAMPLE_ACCEPTANCE.md](HARBOR_SAMPLE_ACCEPTANCE.md)。本文件保留三岸基础范围并说明样板接入，不将全城目标写成已经完成。

## 来源与范围

本轮先从公开仓库 v0.7 提交 `a425667bd2fec0c81f482a89861c88c2acd2641e` 继续开发，随后查到并保留 `codex/v08-materials-and-interiors` 的原 v0.8 检查点 `32ee844`。对照检查点补回全城表面处理、真实外壳用途对应的室内配置和导览明细惰性生成；原工作目录仍不可取回，完整来源及差异见 [QA_V08.md](QA_V08.md)。

源码目录现为 220 栋、4,150 个连续楼层：北岸 48 栋 / 920 层，南岸旧城 96 栋 / 501 层，东湾 76 栋 / 2,729 层。原检查点为 4,374 层；本轮根据实际净空和屋顶空间保留 4,150 层，不沿用旧统计或旧验收结果。集装箱、设备、雕塑与地形不计入可进入建筑。

## 制作目标

1. 区分车漆、皮肤、衣料、皮革、金属和矿物表面的微细节与粗糙度，适量增加近景衣物及软装形变。车辆、人物与家具须分别近看；规则测试或材质参数变化不替代实际画面判断。
2. 在天空环境中加入按实际建筑位置、尺寸和基座生成的近邻代理，按距离与昼夜变化更新。代理用于近似环境反射，不声称实现实时街景反射、SSR 或平面反射。
3. 精细、均衡画质加入深度重建、半分辨率遮蔽与深度感知合成。检查色彩输出、抗锯齿、闪烁、黑屏、轮廓脏边、尺寸改变和资源释放；流畅模式保留直接渲染路径。默认画质保持精细。
4. 旧城小楼使用两房、中央通路、窄实体楼梯与后部电梯；东湾采用四房间用途布局。楼梯穿过真实楼板开口，家具须避开入口、房门、楼梯与电梯路径。入口筛选须进入目标建筑，离开与重载后须恢复外壳。
5. 每栋开放楼层连续，室内最多保留相邻三个精细楼层。外部街区与建筑细节继续按距离加载、释放；保留地面支撑和碰撞，不能用降低默认画质替代资源管理。
6. 保留分车道交通、圆滑转弯、跟车减速、路口放行与出口避堵，回归地铁、渡轮、连续楼梯、电梯和北岸居民路径。新增两岸暂不扩展 240 名北岸居民的住处和工作网络。
7. 客户端与独立多人服务共同使用 `neon-harbor-v08`，支持 8 人房间、玩家、共用车辆与聊天同步，位置范围为 X/Z ±1,800 米、高度上限 460 米。双浏览器需覆盖新区域和高层；GitHub Pages 只发布单人默认客户端，公网多人后端另行部署。

## 验收与交付顺序

1. 完成全部规则测试和静态构建，核对目录实际数量与版本。
2. 执行新增 `city-materials` 浏览器场景，通过可见导览、键盘步行、房门、电梯及退出操作核对真实模型与位置。检查坐标假设与重试逻辑；失败应记录并修复原因。
3. 执行原有城市、交通、地铁、渡轮、楼梯、电梯、居民和双浏览器多人回归。
4. 采集车辆、人物、家具、旧城室内、东湾室内及昼夜海滨的真实 WebGL 画面。已有 v0.7 场景尽量在相同位置、时间、画质、视角和画布分辨率对照；新增室内用实际视图检查通道、家具尺度与表面。
5. 更新 README、QA 和多人说明。截图与对应版本、机位、画质及渲染环境信息放在 `docs/qa/v08/`；车辆及人物材质对照已归档，其他场景由 QA 逐项列明。
6. 提交、推送并运行 GitHub Pages 工作流；等待验证、构建、部署及线上检查完成。核对公开站点版本、提交、资源 SHA-256 和实际加载，再记录发布成功。

## 当前进展

样板接入前，v0.8 基线 `npm test` **226/226 通过**并完成构建。规则仿真覆盖 220 地址往返、4,150 层几何、南岸全部楼层与房间走行，以及东湾逐栋大厅 / 第二层 / 顶层路线。原 20 个浏览器场景初跑 **17 通过、3 失败**，三项修复后在五项复核中全部通过；旧城与东湾补充 **2/2 通过**，独立双浏览器多人 **2/2 通过**。原始失败、最终日志、受测资源摘要和实际截图见 [基线复核证据](qa/v08/verification/final-browser-checks/README.md)。

基线修复了入口与窄梯、东湾家具和通路、外壳加载 / 恢复、内陆山体支撑及后处理的像素边界条纹和色调 / 雾合成。南岸窄梯最终使用公开 Z 慢走，在真实浏览器时钟下通过；受控 60 Hz 时钟方案已放弃。地面与室内慢走速度为 0.8 米/秒，新车船舱内为 0.3 米/秒。

新样板已接入上述三岸基础。首次完整规则出现货栈入口冲突，修复并补齐公交信号 / 行人让行后规则 283/283 通过；静态合批后的最终完整规则 **285/285 通过**，静态构建通过。生活模块与世界购物 / 恢复的独立检查 **14/14 通过**；四项新浏览器首轮为 3 通过、1 渡轮整场超时，最终构建复核另行记录。同条件 1280×800 精细画质昼夜海滨已复查；基线浏览器结果早于新集成，不能直接沿用。至少 20 分钟连续路线、正式资产、真实设备性能、CI 与 Pages 仍须分别登记。

车辆、车漆、人物和走姿的 8 张同条件 WebGL 对照、家具三图及昼夜海滨四图保存于 `docs/qa/v08/`；最终基线还有旧城房间、东湾办公室与观景层三张 High 游戏图。六家样板小店的固定灯光源码美术检查另见 [harbor-art/REVIEW.md](qa/harbor-art/REVIEW.md)，它不代替最终游戏中的居民、交通、阴影与昼夜验收。完整结果继续填写 [QA_V08.md](QA_V08.md)。

## 当前限制

新增室内主要采用共享用途与布局，六家样板店之外尚未逐栋逐房精修；北岸异形外壳也未全部制作逐层工程剖面。220 栋、4,150 层和测试数量不代表 3A 美术完成。北岸生活网络与南岸 20 人新样本范围不同，东湾及其余南岸建筑没有同等经济网络。三种新车船仍为原创程序化资产，正式 GLB 管线、专业角色动画、完整全城和真实硬件 FPS 未完成。软件 WebGL 只提供功能及图像证据，完整兼容性、设备性能与逐房审查须持续补充。

最终规则、浏览器、画面、性能与上线状态分别登记在 [验收记录](QA_V08.md)，未有证据的项目保持待验收。
