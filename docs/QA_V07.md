# v0.7 验证与范围

本次改动是原创命名、街道车流与私人多人房间，不改变此前对房间美术完成度的说明。

- 当前游戏内建筑、楼层、城区、码头、渡轮及道路标牌去除香港关联名称。旧地址 ID 保留，用于存档与既有验收资料兼容。
- 原来共享道路中线的车辆改为分车道环线，使用短弧转弯；在碰撞前跟车减速，在停止线前按错峰信号通行，出口被队列占满时不进入路口。
- 横道让行按实际居民可到达的车辆行驶车道判断，远端居民不再把整条道路预留到完整横穿结束。
- 停放在路口附近、未阻挡当前车道的车辆不再被当成横穿车辆，避免永久让行。
- 原有任务自动驾驶回归路线改用实际通行车道；没有提高任务时限、删除交通或跳过物理碰撞。
- 新增最多 8 人的房间服务和可见菜单入口，提供位置、共用车辆与聊天同步；独立部署方式与限制见 [多人说明](MULTIPLAYER_V07.md)。

## 验证门槛

规则回归包括完整世界的步行/驾驶任务、48 处建筑的房间与楼梯、居民真实出行、交通车辆不穿透、多人服务实际 HTTP/SSE 请求与边界校验。新增完整南岸车流连续三分钟运行检查：十辆行驶车辆各累计行驶超过 700 米，不会因路口旁停车而永远让行。

多人浏览器回归使用两个独立浏览器上下文，操作真实菜单创建和加入同一个房间，检查另一玩家的实际角色模型移动、驾车后两端同一车辆的位置、房间聊天及离开后的角色清理，同时要求无页面运行错误。

发布工作流继续执行完整单人浏览器回归，另加双浏览器多人回归；全部功能检查通过才发布静态客户端，并核验公开网址和构建文件指纹。多人服务代码保留在仓库，GitHub Pages 不运行后端进程。
