## 浏览器实际覆盖

- 从主菜单进入游戏，确认 WebGL 场景完成初始化，并通过键盘行走。
- 靠近车辆、上车、驾驶、制动及下车，检查模式和位置变化。
- 打开地图与委托菜单，接取、查看和取消委托，恢复游戏。
- 射击触发弹药变化与警戒，确认警车实际生成。
- 修改设置并刷新，确认设置保留。
- 导入无效进度时展示错误反馈；确认后重置存档。
- 在手机横屏尺寸下检查界面，使用触屏指针操作移动控件。

该组浏览器用例验证主要交互闭环，并未代表所有任务都已通过真人手动驾驶完成。

## 三项任务的模拟整合验证

额外三项整合测试使用实际城市碰撞体、交通和警车，以输入驱动模拟车辆沿路线行驶，没有直接改写车辆位置来跳过路线。三项任务均在限时内完成。

| 任务 | 模拟完成用时 | 任务限时 |
| --- | --- | --- |
| 港湾速递 | 13.70 秒 | 150 秒 |
| 霓虹环线 | 43.65 秒 | 100 秒 |
| 幽灵信号 | 74.63 秒 | 120 秒 |

这些数字是自动化模拟驾驶的游戏内用时，用来验证路线、碰撞、任务阶段及时间预算。它们不代表真人平均成绩，也不属于三项浏览器端到端场景中的完整驾驶流程。

## 本轮已修复的问题

| 问题 | 修复后的行为 |
| --- | --- |
| 步行时 A/D 横移方向与预期相反 | 左右按键与相机视角下的横移方向一致 |
| 警车模型的材质处理导致运行错误 | 生成警车时可以正常渲染，射击触发追捕场景通过 |

## 仍需扩大验证的范围

本次实际浏览器验收仅覆盖 Chromium。尚未完成 Firefox、Safari、真实 iPhone/Android 设备和不同显卡上的兼容性验证；手机尺寸模拟不等同于真实手机测试。没有测量并承诺稳定帧率、内存上限或电量消耗。

多人、建筑室内、车辆收藏与改装、完整武器体系、NPC 对话与长篇剧情属于后续范围，不能从本次测试通过推导为已经实现。公开站点未在本轮自动发布。

## 复现

```sh
npm ci
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

使用已安装的兼容 Chromium 时，可以通过 `CHROMIUM_PATH=/absolute/path/to/chromium npm run test:e2e` 指定路径。Playwright 会启动本地静态服务，失败证据保存在 `test-results/` 与 `playwright-report/`。
